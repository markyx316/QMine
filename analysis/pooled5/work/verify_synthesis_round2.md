## 0. 先处理一件必须先定的事：第一轮的 Newcombe 实现写反了，被复核方是对的

修订记录在表后单列了一段"与复核表不一致、按实测取值的地方"，声称第一轮复核自己实现的 Newcombe
把上下界的贡献项对调了。**这一条我独立验证，被复核方正确。**

`pooled5_common.newcombe(k1,n1,k2,n2)` 实现的是标准 Newcombe hybrid-score（MOVER）：

```
d = p2 − p1
lower = d − sqrt((p2 − l2)² + (u1 − p1)²)
upper = d + sqrt((u2 − p2)² + (p1 − l1)²)
```

三处证据：

1. **手算复现。** 人物 界面线 `会话与系统指令` 0/9982 → 4/889：
   Wilson(0,9982) = [0, 0.00038478]，Wilson(4,889) = [0.0017508, 0.0115118]，
   lower = 0.0044994 − √(0.0027486² + 0.00038478²) = **+0.172pp**，
   upper = 0.0044994 + 0.0070124 = **+1.151pp**。与 `pooled5_common` 给的 [+0.17,+1.15] 一致，
   与第一轮给的 [−0.25,+0.73] 不一致；把两个贡献项对调正好得到 −0.245 / +0.729。
2. **不依赖区间实现的第二判据。** Fisher 精确检验：人物 0→4 **p = 4.4e−05**、医疗 0→2 **p = 0.0076**，
   两格都显著；一个 0 vs 4/889 的对比给出含 0 的区间在数值上不可能。
3. **金融 0→1 那格两个判据确实打架**：Newcombe [+0.01,+0.59] 不含 0，Fisher **p = 0.087** 不显著。
   被复核方取了保守的一侧（不计入），并把判定重心移到"20 行最小格子"这条与区间实现无关的自设判据上。

**结论：这一段不是辩解，是一处成立的反向修正。** 而且它没有被用来推翻第一轮的结论——
`会话与系统指令` / `生成与编辑` 两条"4/5 规律"照样被降级，理由换成了更硬的最小格子。
做法正确。
