## 二、修订新引入的问题

### R2-1 ★ 「深度线 TVD 也是下界」——深度线两侧**一个共有串都没有**

- **在哪**：正文 §1.4 推论 3（84 行）「**所以本报告的界面线与深度线 TVD 都是下界**」；
  §4 读法 1（"**界面线与深度线的 TVD 都是下界**"）；附录 C 撤回条 1（"全文的界面线与深度线 TVD 因此改写为**下界**"）。
- **重算**：`assistant_top ∩ assistant_random` 的共有字符串数 = **0 / 0 / 0 / 0 / 0**（五域），
  去掉共有串后深度线 TVD **一位不变**：金融 0.5254→0.5254、医疗 0.3921→0.3921、教育 0.2598→0.2598、
  影视 0.4449→0.4449、人物 0.4638→0.4638。这与报告自己的 **T6** 一致——T6 里
  `助手头部1k ＼ 助手随机1k` 与反向格**五域全是 0.0**。
- **为什么要紧**：所依据的机制（"共有的那批串把两个分布拉近"）在深度线上**根本不存在**。
  深度线是全篇最大的一条、也是第 1 条摘要结论的支柱；告诉读者它"是下界"，读者会推断真实差异更大，
  而这条推断没有任何测量支持，并且被同一份报告的 T6 直接否掉。界面线的三个数（0.281→0.595、
  0.309→0.542、0.308→0.308）**本身全对**，问题只在把结论外推到深度线。
- **改法**：把两处「界面线与深度线」改为「**界面线**」，并加一句：
  > 深度线不受此影响：助手头部与助手随机**没有任何逐字共有的串**（T6 五域均为 0.0），去掉共有串前后 TVD 相同。

### R2-2 ★ 「领域体系没有『裸实体』类」——五个领域里有三个有

- **在哪**：§5.1 三种成因第 2 条（501–502 行）「通用框架有「会话与系统指令」和「裸实体」两类，**领域体系没有**——
  教育助手头部残余里合计 30.4%、**人物 38.1%**、金融 41.1% 属于这一类」。
- **重算/对照**：这句话在**教育**（20 个类无裸实体类）与**金融**（18 个类无裸实体类）成立，但
  同一份报告的 **T2** 明摆着：医疗有 `仅给出名称的裸实体查询`、影视有 `裸片名或仅带实体类型词的作品查询`、
  **人物有 `裸名人物身份识别`——而且它是人物的第一大类，占全语料 57.14%（§8.5）**。
  人物那 38.1% 里的 36.9%（84 行中的 31 行）被领域体系判进 `垂类外非人物查询`，
  真正的原因是"**不是人物**的裸实体没有位置"，不是"体系没有裸实体类"。
- **为什么要紧**：数值（38.1% = 1.2+36.9）没错，错的是给这个数的**解释**，而且与 T2、§8.5 直接矛盾。
  这是修订新拆出「判'裸实体'」列时写的新句子（第一轮 B4 的替换文字里没有这条）。
- **改法**：
  > 2. **本体系没有位置**：通用框架有「会话与系统指令」与「裸实体」两类，**教育与金融的体系两类都没有**
  >    （教育助手头部残余里合计 30.4%、金融 41.1%）；**人物有 `裸名人物身份识别`，但它只收人物**，
  >    所以那 36.9% 是"**不是人物**的裸实体"落进了 `垂类外非人物查询`（人物合计 38.1%）。
