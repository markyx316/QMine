这个领域的逐类对照里，最值得先看的是下面这些——其中有一条是“看起来成立、其实不成立”的，放在第 3 条。

**1　“最远的一对是谁”取决于用哪一套体系去量，而且只有一侧判得出来。** 在自上而下的两个层级上，助手头部1k 与助手随机1k 之间比 2025搜索 与助手头部1k 之间更远，两条区间不相交（L1：0.4449 [0.4100, 0.4906] 对 0.237 [0.2245, 0.2756]；L2：0.4625 [0.4342, 0.5035] 对 0.3088 [0.2859, 0.3514]；pairwise_tvd.csv: TVD低/TVD高）。在自下而上的两个层级上点估计的次序相反（家族：0.2864 对 0.3407；叶：0.3124 对 0.3407），但两条区间大面积重叠（家族 [0.2570, 0.3343] 对 [0.3178, 0.3746]；叶 [0.2833, 0.3588] 对 [0.3200, 0.3768]），这一侧分不出先后。所以“深度差大于界面差”这类总结必须写明是在哪一层上说的，而且在自下而上的两层上本表根本测不出这个次序。

**2　最大的类在三个快照上给出同一个数。** “裸片名或仅带实体类型词的作品查询”在 2025搜索 与助手头部1k 都是 42.408%（matrix_td_l1.csv: 各快照_占比%），差 -0.000pp、Newcombe 区间 [-3.247, 3.303]（newcombe_td_l1.csv）；2026搜索 的 44.154% 与助手头部1k 的差同样不显著（[-4.994, 1.558]）。

**3　反例：这不能读成“这个类不受界面影响”。** 同一个类在两个搜索快照之间是 42.408% → 44.154%，差 1.746pp、区间 [0.372, 3.118]，显著（newcombe_td_l1.csv）。1.746pp 在两侧各 9,998 / 9,999 行上测得出来；而助手头部1k 只有 955 行，它自己的 Wilson 区间就宽到 [39.311, 45.567]（matrix_td_l1.csv），半宽超过 3pp。所以“42.408 = 42.408”说明的是**助手快照分辨不出 3pp 以内的差别**，不是两边真的一样。在这张表里，“差不多”和“测不出”长得一模一样，必须靠区间宽度分开。

**4　份额相同不等于内容相同。** 还是这个类：2025搜索 与助手头部1k 内部的叶分布 TVD=0.2362，同源噪声上界 0.0836，超出噪声（intent_leafmix.csv: 内层TVD/同源噪声上界/超出噪声）；主导叶从“影视文学动漫作品名称查询”（34.69%）换成“影视视频资源查询（合并后目标）”（28.15%）。

**5　那个“相等”在 L2 上是两股力抵消出来的。** 同一对快照，BARE_TITLE_LOOKUP__1 从 8.772% 降到 3.979%（[-6.002, -3.260]），BARE_TITLE_LOOKUP__4 从 3.451% 升到 8.272%（[3.193, 6.770]），两条都显著、方向相反、量级相当（newcombe_td_l2.csv）。

**6　全域最稳的类是成人/限制级内容。** 四个快照两两 6 对比较**一条都不显著**（newcombe_td_l1.csv）；合并成搜索、助手两侧后差 0.176pp、区间 [-0.235, 0.767]（interface_td_l1.csv）。全语料 214 行，各快照条数为 2025搜索 102、2026搜索 90、助手头部1k 13、助手随机1k 9（matrix_td_l1.csv: 各快照_条数；条数只说明该快照里有多少行，跨快照的比较看占比）。按引用护栏，这类行只给条数、不引原文。

**7　叶层只有一个叶在任何一对快照之间都测不出差别。** “查询影视节目观看入口”：2.891 / 2.920 / 2.513 / 1.833%（matrix_bu_leaf.csv），6 对比较全部不显著（newcombe_bu_leaf.csv）；家族层的同名家族同样是 0 条显著（newcombe_bu_family_final.csv）。

**8　助手头部1k 的两个“特征类”不同质，其中一个是一部剧。** 对其余每一个快照都显著更高的只有“查询剧情梗概或结局剧透”6.283% 与“查询作品演员表与角色信息”4.188%（signature_td_l1.csv），但两者来源不同。“查询作品演员表与角色信息”在这个快照的 40 行里有 22 行是同一部 8 月下旬在播的剧《醒来》（自算：parquet 与 labels_full.csv 按行位置对齐后逐行数含该剧名的串；两个搜索快照各 0 行），剔掉这 22 行重算，它对 2025搜索、2026搜索、助手随机1k 的三条 Newcombe 区间全部含 0——它是一部在播剧，不是界面特征。“查询剧情梗概或结局剧透”的 60 行里有 18 行同样来自这部剧，剔掉后三对仍都显著（自算，同一口径）。随时间走的题材不归因于界面；姊妹报告《POOLED5_2026 领域深挖》对这两个类的处理也是只报数、不下界面结论。常被当作助手标志的“获取片段、台词或混剪等衍生内容”不在名单里——它在助手两层之间是 10.262% 对 12.424%，差 2.162pp、区间 [-0.672, 4.993]，不显著（newcombe_td_l1.csv）。

**9　唯一通过可检出性的“只在搜索侧出现”，是一部剧的分集查询。** ACCESS_SPECIFIC_EPISODE__3 搜索侧 61 行、助手侧 0 行，另一边期望 5.91 行、P(0)=0.0027（interface_td_l2.csv）；但这 61 行 100% 落在“查询《逆爱》电视剧在线观看资源（合并后目标）”这一个叶里（matrix_td_l2.csv: 主导叶占比%）。是一部剧，不是一类能力的缺口。

**10　唯一独占单个快照的类只有 11 行。** CHANNEL_RESOURCE_ACCESS__1 的 11 行全在 2026搜索（matrix_td_l2.csv: 独占快照）；它对 2025搜索 的缺席是**真缺席**（期望 9.21 行、P(0)=0.0001），对两个助手快照则是“不可判定”（P(0)=0.606 与 0.5971，absence_td_l2.csv）。这 11 行是同一部境外影片系列加网盘渠道词，按护栏不引原文。

把这十条放在一起，可以概括成一句话：**这个领域里四个快照的差别主要落在“要一个入口”这一侧的配比上；“要一段文字”那一侧只有“查询剧情梗概或结局剧透”经得起剔除单剧之后的复算（第 8 条），不能整体当成界面特征。而一旦一个类在两个快照上给出接近的数，先别下结论，要么是助手侧的区间撑不出差别（第 3 条），要么是份额相同而里面的叶已经换了人（第 4 条）。**

**谁排第一。** 2025搜索、2026搜索、助手头部1k 三个快照的首位都是“裸片名或仅带实体类型词的作品查询”（42.41% / 44.15% / 42.41%，表 2.2-L1）；只有助手随机1k 换了人，首位是“剧情设定讨论与同人假设问答”36.151%（matrix_td_l1.csv）。次序上的远近也不一样：2025搜索 与助手头部1k 的前五里有 4 个重合、首位相同，2026搜索 与助手随机1k 只重合 2 个，秩相关 rho 只有 0.0639（pairwise_tvd.csv）——后面这一对的类目次序几乎不相关。

**同样重要的是不动的那一半。** 17 个类里有 4 个在 6 对比较中显著的不超过 2 对（newcombe_td_l1.csv）：获取成人或限制级内容 0 对、获取未删减或未遮挡版本 0 对、下载或安装影视App与排障 1 对、按演职人员反查作品列表 2 对。但两个 0 的含金量完全不同：成人类全语料 214 行、助手侧 22 行（interface_td_l1.csv），区间把界面差压在 [-0.235, 0.767] 之内，这是一个有信息的“没差别”；未删减类全语料只有 30 行、助手侧 1 行，它的“不显著”是没有检出力，不能读成稳定。

**最接近“同一个数”的一组。** “导航到指定影视站点或平台”在三个快照上是 5.241 / 5.001 / 5.236%（matrix_td_l1.csv），2025搜索 与助手头部1k 差 -0.005pp、区间 [-1.328, 1.649]（newcombe_td_l1.csv）。只有助手随机1k 掉到 1.222%，并且对其余每一个快照都显著更低（signature_td_l1.csv: 最弱一对的区间端点pp = -2.479）。

**架构师事前预估偏在哪。** 17 个类里只有 9 个带预估值（matrix_td_l1.csv: 架构师预估占比）。“最准”“最远”取决于口径，两个口径给出不同的答案。按倍数（交付全语料占比% ÷ 预估的百分数）：最准的是“获取作品的在线播放入口”，预估 0.32 即 32%、交付 33.769%，1.06 倍；最远的是“获取未删减或未遮挡版本”，预估 0.01 即 1%、交付 0.137%，预估是交付的 7.3 倍。按百分点差（两者相减）：最准的是“查询剧情梗概或结局剧透”，预估 1.3% 对交付 1.231%，差 0.069pp；最远的换成了“导航到指定影视站点或平台”，预估 1.2% 对交付 4.951%。更值得注意的是缺口而不是偏差——**全语料最大的类“裸片名或仅带实体类型词的作品查询”（9,263 行、42.231%）根本没有预估值**。事前没有人给“文本判不出意图”留一个类目，它却是这个领域最大的一块。

**谁排第一。** 两个搜索快照的首位叶都是“免费电视剧全集在线观看查询”（18.384% / 14.751%），助手头部1k 是“影视视频资源查询”13.717%，助手随机1k 是“影视动漫剧情信息查询”37.373%（matrix_bu_leaf.csv）。19 个叶在 4 个快照里全部出现，独占某快照的是 0 个（表 1-总览）。

**一条看起来成立、其实是撞上的。** “电影资源查询”在 2026搜索 是 7.341%、在助手头部1k 是 7.330%，差 -0.011pp、区间 [-1.589, 1.884]，不显著（newcombe_bu_leaf.csv）。读成“电影资源在两个界面一样常见”是错的：同一个叶在 2025搜索 只有 5.181%，到 2026搜索 的 +2.160pp 是显著的（[1.489, 2.833]）。这个“相等”是在一个正在移动的量上取到的一个瞬时值——换 2025搜索 做锚，同一对界面比较立刻变成 +2.149pp 且显著（[0.594, 4.025]）。**界面结论换个年份锚就翻转，说明它测的是年份，不是界面。**

**一年之内涨得最多的两个叶，主导意图没换人。** 日韩泰剧在线观看 2.090% → 6.631%（差 4.540pp、[3.982, 5.109]）、电视剧与短剧查询推荐 3.401% → 7.491%（差 4.090pp、[3.466, 4.721]），两条都显著（newcombe_bu_leaf.csv）。两年里它们的主导意图都没换人：前者一直是“获取作品的在线播放入口”（60.29% → 73.00%），后者一直是“裸片名或仅带实体类型词的作品查询”（66.76% → 76.64%）（leaf_intentmix.csv）。但“主导意图没换”不等于“构成没变”：两个叶的内层 TVD 是 0.1673 与 0.1091，各自的同源噪声上界是 0.0857 与 0.0741，两条都超出噪声（leaf_intentmix.csv: 内层TVD/同源噪声上界/超出噪声）——意图构成是可测地移动了，主导意图自己的份额也一路上行。能说的是主导意图没换人，不能说含义没有变。这与同串必同标下“年度差异只能来自榜单换血”并不矛盾：换的是题材，构成跟着题材一起动。

**助手两层：排序像，质量不像。** 叶层上助手头部1k 与助手随机1k 的秩相关 rho=0.8273、前五重合 4 个，但首位不同，TVD=0.3124 且超出同源噪声上界（pairwise_tvd.csv: 超出噪声=是）。也就是说，两层之间被改写的是少数几个叶的质量，而不是整张次序表。

**L2 补上了 L1 看不到的抵消。** “裸片名”这个 L1 类在 2025搜索 与助手头部1k 上给出同一个数（42.408%），但它的 6 个子意图里有 3 个显著移动：__1 从 8.772% 降到 3.979%（[-6.002, -3.260]）、__4 从 3.451% 升到 8.272%（[3.193, 6.770]）、__5 从 2.490% 升到 4.398%（[0.734, 3.428]）；另外 3 个不显著（__2 -0.170、__3 -1.061、__6 -0.705）（newcombe_td_l2.csv）。L1 层的那个 0 是这 6 条抵消出来的。靠代表串辨识，__1 是光片名（matrix_td_l2.csv: 代表串，如「南部档案」「色戒」），__4 是片名再加一个“电视剧”这样的消歧词（如「早春晴朗电视剧」「《早春晴朗》电视剧」）——形态不同，L1 的定义把它们放在一起。

**家族层在这个领域几乎就是叶层。** 16 个家族里 14 个正好等于一个叶；只有两个做了合并——“影视动漫剧情与演员表查询”1,372 行 = 影视动漫剧情信息查询 855 + 影视剧演员表查询 340 + 短剧免费观看查询 177（两张 matrix 的全语料条数相加），“电视频道直播与节目表查询”623 行 = CCTV5在线直播观看查询 472 + 电视节目表查询 151。证据就在距离表上：6 对快照里有 5 对的 TVD 在家族层与叶层**一位小数都不差**（0.1376 / 0.3407 / 0.5122 / 0.2696 / 0.5313，pairwise_tvd.csv），只有助手头部1k 对助手随机1k 这一对分开（家族 0.2864、叶 0.3124）。也就是说，家族层只在助手两层的比较上提供了额外信息，其余场合读叶层就够了。

**而那唯一做了三合一的家族，正是被审计判为内部不一致的那个。** “影视动漫剧情与演员表查询”的家族内部一致=否，意见写明“短剧免费观看查询”寻求的是免费观看资源，与剧情、演员表意图不一致（matrix_bu_family_final.csv: 家族审计意见）；而它同时是助手两层的首位家族（18.743% / 40.835%）。

<!--NARR:独有性-->
**先说结论：在 L1 这一层，没有任何一个类真的只属于某一侧；能通过可检出性的“仅某一侧”只出现在 L2，只有一条，而且是一部剧（见本节第四段）。** L1 的 17 个类里，独占某快照 0 个、真缺席 0 条，16 个类在 4 个快照里都出现（表 1-总览）；L2 的 36 个子意图里归属“仅搜索”的有 2 条，其中只有 1 条的缺席判定是真缺席（interface_td_l2.csv: 归属、缺席判定）。唯一的空格是“获取未删减或未遮挡版本”在助手头部1k 的 0 行，判定是**不可判定（样本量不足）**：期望 1.37 行、P(0)=0.255、该快照 97.5% 上界 0.386%（absence_td_l1.csv）。把它写成“助手头部没有这类需求”是错的。

**L2 上能判的只有两条，而且都在同一个类底下。** 36 个子意图里 1 个独占快照、2 条真缺席（absence_td_l2.csv）：CHANNEL_RESOURCE_ACCESS__1 对 2025搜索（期望 9.21 行、P(0)=0.0001）、CHANNEL_RESOURCE_ACCESS__3 对助手随机1k（期望 6.89 行、P(0)=0.001）。同一张表里另有 5 条“不可判定”，这 5 条的缺席快照**全部在助手侧**。

**这个不对称是结构性的，不是发现。** 合并口径下搜索侧 n=19,997、助手侧 n=1,937（interface_td_l1.csv）。0 行落在 955 行的助手头部1k 上，97.5% 上界仍有 0.386%；同样的 0 行落在 9,998 行的 2025搜索 上，上界只有 0.037%（absence_td_l2.csv: 该快照上界%）——差了约一个数量级。所以“只出现在搜索里”比“只出现在助手里”容易达成得多，读这一节必须先看 n。

**界面层面唯一通过可检出性的“仅搜索”，是一部剧。** ACCESS_SPECIFIC_EPISODE__3：搜索侧 61 行、助手侧 0 行，期望 5.91 行、P(0)=0.0027（interface_td_l2.csv），判定真缺席；而它 100% 落在“查询《逆爱》电视剧在线观看资源（合并后目标）”这个叶里（matrix_td_l2.csv: 主导叶占比%）。缺的是一部剧的分集串，不是“按集数直达”这件事本身——同一个 L1 类“直达指定集数的播放页”在助手两侧都有（助手头部1k 0.733%、助手随机1k 1.833%，matrix_td_l1.csv）。

**最后是这一节最重要的限制。** 四个层级的“仅助手”都是 0（表 1-总览），但这是关于**交付分区**的陈述，不是关于需求本身的陈述：体系是在一份以搜索行为主的语料上拟合的——21,934 行里 19,997 行来自两个搜索快照（summary.json: n_rows；interface_td_l1.csv: 搜索n）。如果助手侧存在搜索侧完全没有的需求，体系里很可能根本没有为它准备类目，那些行会被并进既有类，在这张表上表现为“两界面都有”，而不是“仅助手”。姊妹报告《POOLED5_2026 五域同体系对比》已就这一点给过跨领域的量化，这里不重复。

这一节是本报告独有的一件事：**份额和构成是两个独立的坐标。** 只看表 L1-A，会把“同一个数”读成“同一件事”。按 n 从大到小，两个“份额测不出差别、里面换了”的例子：

**一、裸片名类，2025搜索 对 助手头部1k。** 份额 42.408% 对 42.408%（差 -0.000pp、[-3.247, 3.303]，不显著），但内部的叶分布 TVD=0.2362，同源噪声上界 0.0836，超出噪声（intent_leafmix.csv: 内层TVD/同源噪声上界/超出噪声）；主导叶从“影视文学动漫作品名称查询”34.69% 换成“影视视频资源查询（合并后目标）”28.15%（intent_leafmix.csv；两侧 n 分别是 4,240 与 405）。这是全表里 n 最大的一例，也是最干净的一例。

**二、导航到指定影视站点或平台，2025搜索 对 助手头部1k。** 份额 5.241% 对 5.236%（差 -0.005pp、[-1.328, 1.649]，不显著），内层 TVD=0.2695，同源噪声上界 0.2536，超出噪声（intent_leafmix.csv: 内层TVD/同源噪声上界/超出噪声），主导叶从“电影资源查询（合并后目标）”24.43% 换成“视频内容查询与生成”22.0%（intent_leafmix.csv）。对照同一个意图在两个搜索快照之间：内层 TVD 只有 0.0385，同源噪声上界 0.1076，**未超出噪声**（两侧 n 分别是 524 与 500，intent_leafmix.csv）——这一对**本表测不出构成差别**：既不能读成“一年没动”，也不能读成“动了”，两个方向都没有证据。界面那一对虽然判为超出噪声，但 0.2695 紧贴上界 0.2536，而助手头部1k 这一侧只有 50 行，内层分布是 50 行上算的。所以这一例只能作方向性读数。

**第三例不属于这一组：份额动得很小，但那个差是显著的。** 直达指定集数的播放页，2025搜索 对 2026搜索：份额 2.020% → 2.450%，差 0.430pp、区间 [0.020, 0.842]，区间不含 0（newcombe_td_l1.csv）——量级小，但不能当作“份额一样”的例证。它的内层 TVD=0.3919，同源噪声上界 0.1689，超出噪声（intent_leafmix.csv: 内层TVD/同源噪声上界/超出噪声），主导叶从“查询《逆爱》电视剧在线观看资源（合并后目标）”31.19% 换成“免费电视剧全集在线观看查询”37.14%（intent_leafmix.csv）。份额只动了不到半个百分点，里面换掉的是一整部剧。

**反过来看，也有“叶里测不出变化、份额却在动”的。** “影视剧演员表查询”这个叶的三条内层 TVD——2025搜索×2026搜索 0.0262、2025搜索×助手头部1k 0.0138、2026搜索×助手头部1k 0.0323——全部低于各自的同源噪声上界 0.0553 / 0.0785 / 0.0732，三条的超出噪声都是否（leaf_intentmix.csv: 内层TVD/同源噪声上界/超出噪声）。所以只能说“任何一对之间都测不出构成差别”：**这既不是“构成没变”的证据，也不是“构成变了”的证据**。更不能拿它们互相排名：谁更小是噪声内部的次序，没有意义。主导意图始终是“查询作品演员表与角色信息”，占 94.90 / 96.69 / 95.12%。它的份额在快照之间是动的（1.570 / 1.210 / 4.293 / 2.138%，matrix_bu_leaf.csv），但助手头部1k 的 4.293% 要打折看：该叶在这个快照的 41 行里有 23 行是同一部在播剧《醒来》（自算，按行位置对齐），这个高位是一部剧带来的，与导读第 8 条同源。例子上看得出的是形态差别而不是含义差别：搜索侧「智取威虎山演员表」「长安的荔枝演员表」，助手头部侧「醒来演员表」「给我《醒来》的完整演员表」。

**还有一例份额不动而意图构成翻转，但只能作方向性读数。** “电影资源查询”叶在 2025搜索 是 5.181%、在助手随机1k 是 5.397%（差 0.216pp、[-1.111, 1.865]，不显著），内层意图 TVD=0.5115，同源噪声上界 0.2127，超出噪声（leaf_intentmix.csv: 内层TVD/同源噪声上界/超出噪声），主导意图从“裸片名或仅带实体类型词的作品查询”49.03% 变成“剧情设定讨论与同人假设问答”26.42%（leaf_intentmix.csv）。助手随机1k 这一侧只有 53 行，构成是 53 行上算的，不要当成结论。

**哪些类的 n 小到只能报方向。** 获取未删减或未遮挡版本全语料 30 行、助手侧 1 行；处理平台账号或客服问题 88 行、助手头部1k 1 行；凭情节片段反查片名 106 行、搜索侧 41 行（matrix_td_l1.csv、interface_td_l1.csv）。这几类在助手侧的任何结论都建在个位数到几十行上，本表给出的区间已经把这一点写明，但卡片里的百分数容易让人忘记。

**最大的那一块，定义本身就含糊。** “裸片名或仅带实体类型词的作品查询”9,263 行、占 42.231%（matrix_td_l1.csv），它的定义原文写着“具体意图无法从文本判定”。所以任何建立在这个类上的界面或年度对比，只能读作“文本形态的比例一样”，不能读作“用户要的东西一样”——§7 第一例正是它：份额相同而内部叶分布 TVD=0.2362，超出同源噪声上界 0.0836（intent_leafmix.csv: 同源噪声上界/超出噪声）。

**助手侧的两块大头，都建在体系自己标了问题的结构上。** 一块是家族“影视动漫剧情与演员表查询”，家族内部一致=否（matrix_bu_family_final.csv），却是助手两层的首位家族（18.743% / 40.835%）；另一块是叶“视频内容查询与生成”，盲评一致性 3.0，是 19 个叶里唯一低于 4.0 的（matrix_bu_leaf.csv: 盲评一致性），它的主导意图只占 38.7%，而它在助手两层是 12.147% 与 12.424%。逐行标注置信度最低的三个 L1 类（labels_full.csv 的 td_confidence，这一列没有进本报告的表）是凭情节片段反查片名、获取未删减或未遮挡版本、获取成人或限制级内容——最难判的和 n 最小的是同一批类。

**哪些差异被时间和榜单混淆。** 两个搜索快照都在 7 月初、助手约 8 月下旬。收看电视频道直播或查询节目表 1.640% → 3.960%、获取作品的网盘或资源下载渠道 0.110% → 2.970%（matrix_td_l1.csv）这两条年度上升，与“7 月初是什么档期、哪几部剧在播”分不开，本数据无法拆；界面这条线上也有一处：助手头部1k 的“查询作品演员表与角色信息”40 行里 22 行、“查询剧情梗概或结局剧透”60 行里 18 行来自 8 月下旬在播的同一部剧《醒来》（自算），前者剔掉那 22 行后三对比较全部不再显著（导读第 8 条）；同串必同标，所以这里能测到的只有榜单换血，“同一句话含义变了”不可见。叶层的“查询《逆爱》电视剧在线观看资源”（2025搜索 3.411%、2026搜索 0.220%）是同一件事的极端形态：一个以单部剧命名的叶。
