# 科室归属码本（预注册，2026-09-17）

**这份码本在看到任何标注结果之前写定。** 之后如果要改，改动与理由写在文末的「修订记录」里，不回头改正文。

## 为什么要另建一层

两份医疗语料都没有能用的科室标签：

- **医疗8（med-pool8，44,019 行）** 完全没有科室列。它唯一的平台标签 `l2` 只覆盖 1,956 行（4.4%，只有两个
  助手快照），而且是**内容类型**而不是科室（疾病知识 / 药品保健品 / 养生知识 / 医疗服务 / 医疗器械 / 医疗其它）。
- **医疗随机（health-pool3，20,316 行）** 有 `legacy_dept`，20 个取值覆盖全部行，但：
  - **44.6% 是空档**——`(无科室)` 7,911 行 + `无明确科室` 1,155 行；
  - 词表里**没有肿瘤科**。实测 578 行（2.85%）含癌症/肿瘤/化疗/放疗等词，其中 328 行被归进「内科」、
    93 行进「妇产科」、82 行进两个空档，**没有一行被识别为肿瘤相关科室**；
  - 「内科」是个大杂烩：4,104 行里 20.5% 是消化、8.7% 心血管、8.6% 内分泌、7.3% 肿瘤、4.1% 肾、
    2.6% 呼吸、2.4% 神经——这些在国家标准里是七个不同的二级诊疗科目；
  - 还混进了非科室取值：`综合医院`、`医疗服务其它`、`五官科`（已被眼科/耳鼻咽喉科/口腔科取代的旧统称）。

所以科室这一层必须**从 query 文本本身重新判定**，并且两份语料用同一套码本，才能互相比较。

## 词表的来源

一级码取自**《医疗机构诊疗科目名录》**（卫医发〔1994〕第27号，经 2007 年增设「疼痛科」等多次修正；
国家卫生健康委员会现行有效版本）。该名录是卫生行政部门核定医疗机构诊疗科目、填写《医疗机构执业许可证》
的法定标准，共 34 个一级诊疗科目（其中 18 个下设二级），148 个二级诊疗科目。

**在三处偏离名录，每处都有理由：**

1. **内科（03）与外科（04）拆到二级。** 这正是平台标签失效的地方——不拆就复制了它的缺陷。
   二级码直接用名录的 03.01–03.09、04.01–04.08。
2. **增设「男科」。** 名录里没有这个一级科目（对应内容分散在泌尿外科与中医外科），但中国医院普遍设男科门诊，
   平台标签里也有，且语料里量不小。记为 de-facto 科室，报告里单独说明。
3. **性病并入皮肤科**（名录 13.02 本就在皮肤科下），但单独保留二级码，因为它的界面分布值得单看。

## 判定规则

**问一个问题：这条 query 背后的人，应该挂哪个门诊？**（分诊口径，不是「这属于哪个学科」。）

- 知识型提问（「高血压能吃鸡蛋吗」）按**它讲的那个病**所属科室归档，不因为是科普就归到非临床。
- 药品提问：能定位到它治的病就归那个科室（「二甲双胍副作用」→ 内分泌科）；只问药本身而定位不到病
  （「布洛芬和对乙酰氨基酚哪个好」）归 `YP_GENERIC`。
- 症状提问按**最可能的首诊科室**；多科可能时选最常见的那一个，不要选「全科」当逃避。
- 儿童相关一律优先 `EK`（儿科），即使症状本身属于别的系统——分诊现实如此。
- 孕期相关优先 `FCK_CK`（产科）。
- 只有真的定位不到时才用 `QK`（全科/综合），**不是拿不准就用它**。

## 输出约束

每个 query 恰好一个码。不允许多标，不允许自造码。拿不准时**必须**在 `QK` / `WFPD` 里选一个，
而不是硬塞进一个临床科室——宁可少判，不可乱判。
