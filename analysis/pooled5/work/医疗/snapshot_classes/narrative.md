这份表里最值得看的不是“助手和搜索不一样”——那件事姊妹报告已经量过了。值得看的是**哪些类在五个快照上几乎不动**、**哪些看起来动了但区间重叠**、以及**份额没变而里面的叶完全换掉了**。下面十条，每条一句结论加一个带出处的数字。

1. **有两个意图在五个快照上测不出任何差别。** `由自述症状直接索取药品或药膏` 的五个读数是 0.65 / 0.65 / 0.835 / 0.601 / 0.800（matrix_td_l1.csv: 各快照_占比%），极差 0.234pp（同表: 极差pp）；`获取食疗/养生方的做法与搭配` 是 0.68 / 0.73 / 0.418 / 1.202 / 0.600。两个类各自的十组两两对比，Newcombe 区间**全部含 0**（newcombe_td_l1.csv: 显著 列十个 False）。

2. **一条看起来成立、其实不成立的结论。** 叶 `查询食物寒热属性` 在 助手头部1k 里 0 条，而且是叶层唯一一条通过可检出性判定的真缺席（absence_bu_leaf.csv: 期望条数 8.15、P(0) 0.0003）。很容易写成“凉性热性是搜索特产”。但把三层助手合起来（n=2,956），它是 0.846% 对搜索 0.81%，差 0.036pp [-0.268, 0.452]，区间含 0（interface_bu_leaf.csv）；它在 助手语音1k 是 1.500%，**五个快照里最高的一个**（matrix_bu_leaf.csv: 助手语音1k_占比%）。那个 0 是助手**头部这一层**的抽样结果，不是界面事实。

3. **份额没变、里面全换了。** `解读用户本人的检查数值或报告分级` 搜索 4.001% 对助手 3.687%，差 -0.313pp [-0.995, 0.474]，不显著（interface_td_l1.csv）。但它内部的叶分布，2025搜索 对 助手随机1k 的内层 TVD 是 0.6784，同源噪声上界 0.1993，记 超出噪声（intent_leafmix.csv: 内层TVD / 同源噪声上界 / 超出噪声）；主导叶从 `检验指标异常原因查询`（66.82%）换成 `查询疾病治疗与手术方案`（24.14%）。

4. **反过来也有一个：份额变了、主导叶没换——但“构成没变”这半站不住，份额那半还要先扣掉仪器。** `对具体行为、搭配或说法给出是否可行的裁决` 从 2025搜索 2.951% 走到 助手语音1k 26.0%（极差 23.049pp，最高比最低 8.81 倍，matrix_td_l1.csv），是全表最大的一处移动。**这一处不能直接读成需求差异**：这个类的定义就是“要求一个明确的能/不能/真/假判定”（matrix_td_l1.csv: 定义），而语音是 ASR 文本、抽样方式与时间都未知，是非判定句正是口语最自然的形态——这 23.049pp 里有多少来自输入方式本身，本表分不开。表里唯一能把仪器挡在外面的一段是：打字长尾 助手随机1k 已经到 18.838%，语音相对它只多 +7.162pp [3.508, 10.794]（newcombe_td_l1.csv），**所以这 23.049pp 的大头（2025搜索 → 助手随机1k 的 15.887pp [13.556, 18.450]）与语音无关，只有剩下那一段才需要算在输入方式头上。** 构成这一半只有主导叶是稳的：它内部的主导叶在列出的每一对快照上都是 `查询功效副作用与禁忌`（intent_leafmix.csv: 主导是否相同 全为 True）。但**“构成没换”说不成立**：十对里有三对的内层 TVD 超出同源噪声上界——2025搜索 × 助手随机1k 0.2081 对 0.1703、2026搜索 × 助手随机1k 0.1983 对 0.1614、2025搜索 × 助手语音1k 0.1662 对 0.1515（同表: 内层TVD / 同源噪声上界 / 超出噪声）。

5. **五个快照有四个不同的首位类。** 2025搜索 是 `仅给出名称的裸实体查询` 18.56%、2026搜索 是 `查询中药材/食材/茶饮的功效与作用` 17.68%、助手头部1k 又是裸实体 22.13%、助手随机1k 是残余类 19.54%、助手语音1k 是 `对具体行为…裁决` 26.0%（coverage.csv: 首位类目 / 首位占比%）。

6. **年度那条线只有两个类越过 4pp。** 2025搜索 → 2026搜索，20 个意图里 8 个显著，其中 `仅给出名称的裸实体查询` -7.241pp [-8.225, -6.258]、`查询药品的功效与作用` +4.201pp [3.227, 5.175]；另外 12 个类的区间含 0（newcombe_td_l1.csv）。

7. **“极差”和“倍数”两列单独读会骗人。** 叶 `癌症早期症状查询` 的最高比最低是 2.51 倍（助手头部1k 1.253% 对 助手语音1k 0.500%，matrix_bu_leaf.csv），差 -0.753pp [-1.720, 0.101]——它是 30 个叶里**唯一一个十组两两对比全部不显著**的叶（newcombe_bu_leaf.csv）。

8. **架构师的事前预估系统性偏在“个案行动”那一侧。** 高估最多的三个是 `由自述症状直接索取药品或药膏`（预估 5.0%、实际 0.66%）、`对正在发生的具体不适做分诊与处置判断`（4.0% / 0.64%）、`查询中药材/食材/茶饮的功效与作用`（19.0% / 15.84%）——第三名是个**模板类**，不是个案行动类；`对具体行为…裁决`（8.0% / 5.00%）只排第四；低估最多的是 `查询药品的功效与作用`（9.0% / 13.08%）和残余类（3.0% / 6.12%）（matrix_td_l1.csv: 架构师预估占比 / 全语料占比%）。预估是对**整份合并语料**写的，而语料 87% 是搜索行，所以偏高很容易解释成“助手行太少”。但这个解释只对其中两个成立：分诊在 助手随机1k 是 4.709%（预估 4.0%）、行为裁决在 助手随机1k 18.838%、助手语音1k 26.0%（预估 8.0%），都够到了；而 `由自述症状直接索取药品或药膏` 在五个快照上最高也只有 0.835%，预估 5.0% 在**任何一个**快照上都不成立——**这一条是预估本身写高了，不是语料构成的问题。**

9. **助手头部这一层比两个搜索快照都更集中，不是更分散。** 有效类目数（exp(熵)）在 助手头部1k 只有 10.42，低于 2025搜索 的 12.36 和 2026搜索 的 12.85；助手随机1k 反而最高，13.26（coverage.csv: 有效类目数）。集中度的顺序是助手头部 > 搜索 > 助手随机，界面不是这条线的解释变量。

10. **家族层可以跳过，而且它有一处比叶层更差。** 交付的 30 个叶只合并成 27 个家族，差额全部来自两处：1111 + 214 = 1325 与 653 + 507 + 387 = 1547（matrix_bu_leaf.csv 的 全语料条数 相加，与 matrix_bu_family_final.csv 的 全语料条数 逐格相符）。后一处被审计判为混合残留、家族内部一致记“否”，它在 助手随机1k 上排第一（17.936%），而对应的叶只有 15.23%——差出来的是穴位定位和术语释义。

**L2 子意图补上的是 L1 完全看不见的东西。** 最干净的一例是 `在两个或几个选项之间给出裁决`：它在两个搜索快照上的条数一模一样（151 / 151 行，占比都是 1.510%，差 0.000pp [-0.340, 0.340]）。拆到 L2 是两件不同的事——`OPTION_ADJUDICATION__1`（主导叶 `查询食物寒热属性`，占 100.0%；代表串如「桃子是凉性还是热性」）在两个搜索快照是 0.480% / 0.390%、在三层助手**全部 0 条**；`OPTION_ADJUDICATION__3`（主导叶 `药品用法用量查询` 只占 14.6%，代表串如「碘伏和酒精哪个更安全」）在 助手随机1k 2.204%、助手语音1k 2.400%，对 2025搜索 分别是 +1.484pp [0.717, 2.605] 与 +1.680pp [0.876, 2.836]，而在 助手头部1k 只有 1 条（0.104%）（matrix_td_l2.csv / newcombe_td_l2.csv）。**一个总量不动的 L1 类，底下是一个只在搜索出现的子意图和一个只在助手长尾与语音上成规模的子意图。**

**另一例直接解释了 L1 层那个“没有差别”的读数。** `PERSONAL_RESULT_INTERPRETATION__1`（主导叶 `检验指标异常原因查询` 94.9%）在两个搜索快照是 2.871% / 2.450%，在三层助手是 0.731% / 0.802% / 0.400%，六组搜索对助手全部显著、三组助手内部全部不显著；`__2`（主导叶 `医学术语与检查指标含义查询` 只占 25.4%）方向相反，助手随机1k 5.010% 对 2025搜索 1.410%，+3.600pp [2.384, 5.149]（newcombe_td_l2.csv）。L1 层那个 -0.313pp 的净差，是这两股方向相反的量抵消出来的。

**先说结论：医疗这个领域没有任何一个界面独有的意图可报。** 20 个 L1 意图在五个快照上全部出现，没有一个 0 条（表 L1-F）；叶层 30 个、家族层 27 个也都是“两界面都有”，仅搜索 0 个、仅助手 0 个（interface_bu_leaf.csv / interface_bu_family_final.csv 的 归属 列）。

**唯一一条通过可检出性判定的“仅搜索”条目在 L2 层。** `OPTION_ADJUDICATION__1` 在助手侧 2,956 行里 0 条，期望条数 12.86、P(0) 0，判真缺席（interface_td_l2.csv: 缺席判定）。但同一个类在**逐快照**的表里三次都判“偏少但证据弱”：助手头部1k 期望 3.79、P(0) 0.0224；助手随机1k 3.95 / 0.019；助手语音1k 3.96 / 0.0189（absence_td_l2.csv）。同一件事，分三层看证据不够，合起来才够——**这就是检出力不对称的具体形状**：助手一层约一千行，搜索两个快照合起来 19,996 行，n 差了二十倍。同样是 0 条，在 958 行的助手快照里单侧 97.5% 上界仍有 0.384%（absence_bu_leaf.csv: 该快照上界%），而 47 个 L2 子意图里，有四个的全语料占比本身就低于这个上界（matrix_td_l2.csv: 全语料占比%，最低的两个都是 0.240）——对这一档的类，助手任何一层的 0 条都不构成证据。

**叶层与家族层各有一条真缺席，而且是同一条，并且它不是界面结论。** `查询食物寒热属性` 在 助手头部1k 0 条，期望 8.15、P(0) 0.0003（absence_bu_leaf.csv / absence_bu_family_final.csv）。它在 助手随机1k 有 10 条（1.002%）、助手语音1k 有 15 条（1.500%），界面切法上 0.036pp [-0.268, 0.452] 含 0。**所以这是助手头部这一层的缺席，不是助手的缺席。**

**有一条必须明确标成不可判定。** `CARE_LOGISTICS_COST_DURATION__3` 在 助手头部1k 同样 0 条，但期望条数只有 2.4、P(0) 0.0908，判定是“不可判定（样本量不足）”（absence_td_l2.csv）——它不能写成发现。与它对照的 `DISEASE_DEFINITION_CAUSE__6`（主导叶 `医学检查项目查询` 90.8%）在同一个快照 0 条，期望 5.66、P(0) 0.0034，才够判真缺席。两条的差别只在期望条数，也就是只在这个类本身有多大。

**最后是必须写出来的限制。** 这套体系是在一份 **87% 是搜索行**的合并语料上拟合出来的（22,952 行里搜索 19,996 行）。所以“没有任何一个类只出现在助手里”是关于**交付分区**的陈述，不是关于**需求本身**的陈述——助手侧特有的东西可能根本没有类目可落，被并进了残余。这一点在数上看得见：`处理非健康或无法归入上述意图的残余` 在 助手随机1k 占 19.539%、助手头部1k 17.745%、助手语音1k 14.7%，而两个搜索快照只有 4.381% / 4.551%（matrix_td_l1.csv）。**助手侧每五到七行就有一行落在一个按排除法定义的类里，那一格里有什么，本表答不了。**

<!--NARR:路线交叉-->
意图体系自上而下写出、聚类树自下而上长出，两者独立。所以“同一个意图在不同快照里落到不同的叶”是一个测量。本节只看两侧都 ≥30 行的格子。

**最强的一例：份额测不出差别，内部完全换掉。** `解读用户本人的检查数值或报告分级` 在界面切法上是 4.001% 对 3.687%，差 -0.313pp [-0.995, 0.474]，区间含 0（interface_td_l1.csv）。但它内部的叶分布，2025搜索 对 助手随机1k 的内层 TVD 高达 0.6784，同源噪声上界 0.1993；对 助手语音1k 是 0.6399，上界 0.2459。两格都记 超出噪声（intent_leafmix.csv: 内层TVD / 同源噪声上界 / 超出噪声）。主导叶从 `检验指标异常原因查询`（66.82%）换成 `查询疾病治疗与手术方案`（24.14%）；语音那一端换成 `健康指标正常值范围查询`（27.78%）。叶层的两个读数把这件事钉死：`检验指标异常原因查询` 搜索 3.076% 对助手 1.353%，-1.722pp [-2.158, -1.186] 显著；`查询疾病治疗与手术方案` 搜索 1.925% 对助手 9.066%，+7.141pp [6.138, 8.245] 显著（interface_bu_leaf.csv）。**同样是“带着自己的数值来问”，搜索侧落在“这个指标为什么高”，助手侧落在“那接下来怎么办”。** 例子只在搜索侧对得上：2025搜索 的流量最高行「总胆红素偏高说明什么」落在 `检验指标异常原因查询`（examples_td_l1.csv）。助手侧在例子表里唯一能对上这条路线的行来自语音层——「肩袖修复手术4个月后仍感觉里面酸胀这正常吗」，同一个意图，落在 `查询疾病治疗与手术方案`（examples_td_l1.csv / examples_bu_leaf.csv）；助手随机1k 这一格的例子表里没有落在该叶的行，所以随机层这一端能依靠的只有 TVD 与上面两条叶层区间。

**第二例：五个快照上份额最稳的那个意图，内部也换了。** `寻找疾病的治疗或缓解方案` 十组里九组不显著（见“意图层”），但 2025搜索 对 助手随机1k 的内层叶分布 TVD 是 0.3542，同源噪声上界 0.1815；对 助手语音1k 是 0.3095，上界 0.206。两格都记 超出噪声（intent_leafmix.csv: 内层TVD / 同源噪声上界 / 超出噪声），可读。主导叶从 `查询疾病最快最有效治疗方法`（51.64%）换成 `查询病症用药推荐`（28.21%）；语音那一端同样换成 `查询病症用药推荐`（31.15%）。搜索侧的流量最高行是「牙疼怎么止疼最快」，落在 `查询疾病最快最有效治疗方法`；助手随机1k 落在新主导叶 `查询病症用药推荐` 的例子是「帕金森吃什么药」与「脚后跟退皮用什么药」（examples_td_l1.csv）。**总量不变，落点从“最快最有效”挪到“吃什么药”。**

**第三例是反面教材：总量精确不变，而“里面有没有换”这张表答不了。** `在两个或几个选项之间给出裁决` 在两个搜索快照上都是 151 行、1.510%，差 0.000pp [-0.340, 0.340]。表里这一格的内层 TVD 是 0.1722，主导叶从 `查询食物寒热属性`（37.75%）记到 `药品用法用量查询`（32.45%）（intent_leafmix.csv）。**但 0.1722 低于这一格的同源噪声上界 0.2053，超出噪声 记 False**（intent_leafmix.csv: 同源噪声上界 / 超出噪声）。按本报告“TVD 低于同源噪声上界就不可读”这条规则，**这 151 行内部的构成有没有变，本表测不出**——主导叶的换位不能当成“换了”的发现；反过来，低于上界也不能拿来说“没换”，两个方向都只能写测不出。 这一格能说的只有全快照口径上两个叶各自的独立显著移动：`查询食物寒热属性` 0.960% → 0.660%，-0.300pp [-0.554, -0.051]；`药品用法用量查询` 1.590% → 2.090%，+0.500pp [0.127, 0.876]（newcombe_bu_leaf.csv）——那是叶在整个快照里的份额，不是这 151 行内部的构成证据。

**第四例方向相反：份额动了，主导叶没换，但“构成没动”站不住。** `对具体行为、搭配或说法给出是否可行的裁决` 的份额从 2025搜索 2.951% 到 助手语音1k 26.0%（+23.049pp [20.403, 25.874]），是全表最大的一处移动——这一端的仪器归因见“导读”第 4 条，份额本身不能直接读成需求差异。构成这一半只有主导叶是稳的：它内部的主导叶在列出的每一对上都是 `查询功效副作用与禁忌`（2025搜索 45.76%、2026搜索 49.47%、助手头部1k 43.33%、助手随机1k 44.15%、助手语音1k 49.23%）。但 超出噪声 这一列把“构成没变”否掉了：十对里有三对越过了自己的同源噪声上界——2025搜索 × 助手随机1k 0.2081 对 0.1703、2026搜索 × 助手随机1k 0.1983 对 0.1614、2025搜索 × 助手语音1k 0.1662 对 0.1515（intent_leafmix.csv: 内层TVD / 同源噪声上界 / 超出噪声）。剩下七对记 False，其中内层 TVD 最大的一格恰恰是 助手头部1k × 助手语音1k 的 0.3179 对上界 0.3398——那一格 n_a 只有 30，上界被 n 撑得很高，**这一格是测不出，不是没变**。**所以“份额变了”和“构成变了”是两件独立的事：这个意图份额移动全表最大，而它的叶混合在搜索对助手长尾这条线上测得出变化，在另外七对上测不出。**

**倒过来看，叶内部的意图混合在年度上最不稳的是 `药品及医疗产品信息查询`**：2025搜索 对 2026搜索 内层 TVD 0.2600，而这一格的同源噪声上界只有 0.0650，记 超出噪声（leaf_intentmix.csv: 内层TVD / 同源噪声上界 / 超出噪声）；主导意图仍是 `仅给出名称的裸实体查询`，但占比从 86.34% 掉到 60.34%——同一个叶，2026 年里有四成不再是裸实体。这与意图层裸实体 -7.241pp 的下降是同一件事的两个切面。

**这份表答不了的第一类问题：助手头部那一层里的小格子。** 助手头部1k 只有 958 行，其中 `对正在发生的具体不适做分诊与处置判断` 2 条、`在两个或几个选项之间给出裁决` 3 条、`查询药品用法用量与服用时机` 3 条（matrix_td_l1.csv: 助手头部1k_条数）。这三格参与计算出来的倍数（分别是 22.56、10.54、7.04 倍，同表: 最高比最低倍数）不要读——它们的分子分母都在个位数上。叶层同理：`身体疼痛病因查询` 在 助手头部1k 6 条、`医学术语与检查指标含义查询` 9 条。

**第二类：类目定义本身就含糊的那几个。** 盲评一致性最低的三个叶是 `查询食物寒热属性` 2.0、`查询疾病治疗与手术方案` 3.0、`中医方剂配方与食疗搭配吃法查询` 3.0，其余 27 个叶都是 4.0（matrix_bu_leaf.csv: 盲评一致性）——**前两个恰好是本报告说得最多的两个类**。主导意图占比最低的三个叶与这一批只重合两个：`查询疾病治疗与手术方案` 27.1% 与 `中医方剂配方与食疗搭配吃法查询` 32.6% 两边都在，第三个 `血糖与糖尿病问题查询` 31.6% 的盲评一致性却是满分 4.0；反过来，盲评最低的 `查询食物寒热属性` 主导意图占比有 55.1%（同表）。**两把尺子量的不是同一件事**——盲评一致性问“这个叶里的行看起来像不像一个类”，主导意图占比问“这个叶和自上而下的切法对不对得齐”，不要合起来读。家族层还多一处：`疾病治疗与手术方案查询` 的 家族内部一致 记“否”，审计意见直接称它为混合残留。**凡是围绕这几个类的结论，区间只反映抽样误差，不反映“这一行到底该不该在这里”的误差。**

**第三类：被仪器和时间混淆的差异。** 两个搜索快照都在 7 月初，助手约 8 月下旬，语音时间未知；语音是 ASR 文本（无标点、约 40 字截断、抽样方式未知）。所以随季节走的题材——`查询中药材/食材/茶饮的功效与作用`（2026搜索 17.684%、助手随机1k 4.208%）、`查询食物寒热属性`——它们在搜索与助手之间的落差里，有多少是七月和八月的差别，本表分不开；语音层上的读数都必须先算在 ASR 与导出口径头上，**而且不止于长度、完整度与重复串，份额同样在内**：语音是 ASR 文本，抽样方式与时间都未知，问句形态本身会被输入方式改写，所以像 `对具体行为、搭配或说法给出是否可行的裁决`（助手语音1k 26.0%）这种以“能/不能、真/假”判定句为定义的类，它在语音层的份额里有多少来自输入方式，本表分不开（见“导读”第 4 条的拆分）。

**第四类：标注层本身。** 本次是 `mode=fast`，**单标注员，kappa 不存在，不是 1.0**。本报告每一个占比都建立在一个没有第二意见校验的标注层上。另外，同一个字符串在一次运行里必然拿到同一个标签，所以 2025 与 2026 之间的差异只能来自榜单换血，**“同一句话的含义变了”本方法测不到**。

**第五类：不能引用的行。** 引用护栏是三层：风控图层命中 1,147 行、一组与领域无关的硬规则、运行自己点名过的 95 个具体字符串。三层互不包含，所以全语料 22,952 行里最终的可引行是 **21,763 行**（summary.json: quotable_rows / n_rows），比只扣掉风控图层那一层（22,952 − 1,147）还要少。涉及个人信息、露骨内容或未成年人具体情形的行，本文一律只作概括、不引原文——例如 助手头部1k 残余类的 170 行里（matrix_td_l1.csv: 助手头部1k_条数），姊妹报告复核计出 18 行是带性暗示的身体形态短句，本文不给原文；姊妹报告还在 助手随机1k 的 `解读用户本人的检查数值或报告分级`（58 条）与 `对正在发生的具体不适做分诊与处置判断`（47 条）里各点出过含未成年人具体伤情或个人隐私叙述的行，本文同样只作概括。**这意味着本报告例子最少的几格，恰好是内容最敏感的几格。**
