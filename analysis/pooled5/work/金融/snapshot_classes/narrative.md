这份逐类对照最值得看的不是“助手和搜索不一样”——那件事已经在姊妹报告里量过了。值得看的是三类东西：**哪些类在五个快照上几乎不动、哪些看起来动了但区间重叠、哪些份额没变而内部换了东西。**

1. **全表最稳的一个类是“查询交易日程与市场状态”。** 五个快照的占比是 0.41% / 0.39% / 0.421% / 0.405% / 0.5%，极差 0.11pp（matrix_td_l1.csv: 极差pp），并且是 18 个意图里**唯一一个 10 对两两比较全部不显著**的类（newcombe_td_l1.csv: 显著列，该类 10 行全为 False）。它同时是架构师事前预估偏得最多的一个方向：预估 3.0%、实际全语料 0.41%（matrix_td_l1.csv: 架构师预估占比 / 全语料占比%）。
2. **一条看起来成立、其实不成立的结论：“查询历史价格走势图 在两个界面上一样多”。** 在 n 最大的那个切法上它确实测不出差别——搜索 1.51% vs 助手 1.226%，差 -0.284pp [-0.668, 0.209]，区间含 0（interface_td_l1.csv）。但这不等于它不动：2025搜索 1.16% → 2026搜索 1.86%（+0.700pp [0.363, 1.043]，显著），助手头部1k 2.526% → 助手随机1k 0.608%（-1.918pp [-3.168, -0.830]，显著）（newcombe_td_l1.csv）。**两侧各自在动、方向相反，合并以后互相抵消。**把并层后的“不显著”读成“这个类在两个界面上一样”是错的；它只说明两个已经各自不均匀的池子平均数碰巧接近。“核实金融平台真伪与合法性”是同一个形状：并层差 +0.096pp [-0.306, 0.610] 不显著，而 2025搜索 1.95% → 2026搜索 0.65%（-1.300pp [-1.622, -0.991]，显著）。
3. **份额没变、里面完全换了：汇率换算查询。** 这个叶在两界面上是 6.821% vs 6.503%，差 -0.318pp [-1.227, 0.691] 不显著（interface_bu_leaf.csv）。但叶内部的意图归属翻了个面：2026搜索 里 73.17% 的行被判为“查询金融资产实时行情”，助手语音1k 里 67.57% 被判为“计算具体金额或利率”（leaf_intentmix.csv: 内层TVD 0.4792，同源噪声上界 0.1039、超出噪声=是）。前者形如「日元对人民币汇率」，后者形如「一亿缅币是多少人民币」。
4. **行情类一年涨了 10.116pp，但涨的只是它三个子意图中的一个。** QUOTE_LOOKUP__2（代表串「上证指数」/「美股」）32.356% → 42.054%，+9.698pp [8.362, 11.028]；而 QUOTE_LOOKUP__1（代表串「今日金价」）15.563% → 15.532%，差 -0.032pp [-1.036, 0.973]，**区间含 0**（newcombe_td_l2.csv）。只看 L1 会把这读成“行情需求整体上移”。
5. **叶层 68 个类里有 22 个，极差的两端都落在三个助手快照之间**（matrix_bu_leaf.csv: 最高快照 / 最低快照），也就是说这些类最大的一条缝不在界面之间。汇率换算查询 就是一例：助手语音1k 11.1% vs 助手随机1k 2.026%，+9.074pp [6.973, 11.289] 显著（newcombe_bu_leaf.csv）。
6. **排名稳定不等于份额稳定。** 残余类“其他或无法判定的非金融查询”在五个快照的快照内排名是 3 / 3 / 2 / 2 / 3（matrix_td_l1.csv: 各快照_排名），占比却从 6.401% 到 16.819%，差 +10.418pp [8.159, 12.922] 显著（newcombe_td_l1.csv: a=2026搜索 b=助手随机1k）。
7. **“助手侧更常问每日答题答案”是并层造出来的。** 并层看：搜索 0.835% vs 助手 1.6%，+0.765pp [0.348, 1.299] 显著（interface_td_l1.csv）。但助手随机1k 只有 0.203%，**比 2025搜索 的 1.14% 还低**（-0.938pp [-1.209, -0.372] 显著）；整个助手侧的高位全部来自 助手头部1k 的 3.474%（matrix_td_l1.csv）。另外这是逐日更新的题材，两个搜索快照在 7 月初、助手约 8 月下旬，**这项差异不得归因于界面**。
8. **没有任何一个类只出现在助手里**——四个层级的“仅助手”都是 0（表 1-总览）。**但这是关于交付分区的陈述，不是关于需求本身的陈述**：这套体系是在一份 87% 是搜索行的语料上拟合出来的，助手侧独有的东西完全可能已经被并进了残余类，而残余类正是助手随机1k 里占比第二高的类（16.819%）。
9. **“股吧在助手上完全没有”也只在一半意义上成立。** L1 层“进入个股股吧讨论区”在五个快照都出现（助手头部1k 0.211%、助手随机1k 0.101%、助手语音1k 1.0%）；L2 层它被切成 6 个子意图，其中**只有 STOCK_FORUM_VISIT__4 和 __5 在三个助手快照上全为 0 条**，归属判为“仅搜索·真缺席”（interface_td_l2.csv: 另一边期望条数 57.13 与 43.62、另一边P(0)=0、归属）；其余 4 个都在助手侧留下了行——但 __2、__3、__6 在**单个**助手快照上仍各有真缺席记录（absence_td_l2.csv 共 11 条真缺席），只有 __1 连单快照的真缺席都没有。
10. **黄金在叶层被切成五个叶，五个叶的最高快照全是 助手头部1k**：黄金价格与行情查询 3.263%、实时国际金价查询 1.789%、黄金价格及黄金股票行情查询 1.789%、黄金价格查询 1.579%、今日金价查询 1.474%（matrix_bu_leaf.csv: 助手头部1k_占比%）。任何单看其中一个叶的读法都会低估这个题材；而金价随时间走，快照时间不同，**这个形状不得归因于界面**。

<!--NARR:意图层-->
**首位类目在五个快照里只换过一次。**“查询金融资产实时行情”在 2025搜索、2026搜索、助手头部1k、助手语音1k 都排第一（54.24% / 64.36% / 50.42% / 19.5%），只有 助手随机1k 的第一名换成了“寻求个股买卖与持有决策建议”27.96%（coverage.csv: 首位类目 / 首位占比%）。但这四个“第一”之间的差距本身就很大：从 19.5% 到 64.36%，行情类的极差是 55.643pp（matrix_td_l1.csv: 极差pp），是全层最大的一项。

**极差最大的四个类，四个方向各不相同。** 行情 55.643pp（最高 2026搜索、最低 助手随机1k）、寻求个股买卖与持有决策建议 27.113pp（最高 助手随机1k、最低 2025搜索）、进入个股股吧讨论区 14.03pp（最高 2026搜索、最低 助手随机1k）、获取银行或支付账户操作指引 12.67pp（最高 助手语音1k、最低 2026搜索）。**“最高快照”这一列不是一个界面标签**：18 个类里最高快照落在 2025搜索 的 1 个、2026搜索 的 2 个、助手头部1k 的 4 个、助手随机1k 的 5 个、助手语音1k 的 6 个（matrix_td_l1.csv: 最高快照）。

**稳的那部分同样要写出来。** 除了极差 0.11pp、10 对全不显著的“查询交易日程与市场状态”，还有两个类的极差在 1pp 附近：“识别陌生电话号码归属”1.008pp（1.21% / 1.09% / 0.842% / 0.203% / 0.4%）与“寻求应急或无征信门槛借款渠道”0.34pp。但后两个不能和第一个并列：电话归属的并层差 -0.673pp [-0.922, -0.323] 是显著的（interface_td_l1.csv），借款渠道也有两对显著（2025搜索→2026搜索 -0.12pp、2026搜索→助手语音1k +0.34pp）。**只有交易日程那一个类，在这份表里找不到任何一对可读的差异。**

**排名和份额要分开读。** 残余类的快照内排名是 3 / 3 / 2 / 2 / 3，几乎不动，份额却跨了 10.418pp。反过来，“查找官方渠道与客服入口”的份额极差只有 4.32pp（8.12% / 4.28% / 5.16% / 4.36% / 8.6%），排名却从第 4 掉到第 9（matrix_td_l1.csv: 助手随机1k_排名）——因为它周围的类在动。**排名是相对量，份额是绝对量，两者在同一张表里给出不同的印象，不要混用。**

**架构师的事前预估偏在哪。** 低估最多的是残余类（预估 3.0%、实际 8.21%）和行情类（预估 50.0%、实际 55.02%）、股吧（预估 8.0%、实际 10.9%）；高估最多的是交易日程（预估 3.0%、实际 0.41%）、市场动态（预估 3.0%、实际 0.91%）和产品比较（预估 2.5%、实际 0.41%）（matrix_td_l1.csv: 架构师预估占比 / 全语料占比%）。**但这张对照本身有一个结构性限制**：预估是**一个数**，而同一个类在五个快照上的占比可以跨 55.643pp。行情类的预估 50.0% 同时要对上 助手随机1k 的 8.71% 和 2026搜索 的 64.36%，它不可能同时对得上。所以“预估−实际”只能读成“对这份合并语料的预估偏差”，不能读成“架构师对某个界面判断错了”。

**一条不能从这层读出来的东西：** 并层的“界面差异”有 13 个类显著（interface_td_l1.csv: 显著）。但有三个类的**最高与最低快照都落在助手三层之内**——查询历史价格走势图、核实金融平台真伪与合法性、获取每日答题活动答案（matrix_td_l1.csv: 最高快照/最低快照）——**其中前两个在并层上恰恰测不出界面差异**（差 -0.284pp [-0.668, 0.209] 与 +0.096pp [-0.306, 0.610]）。它们最大的那条缝在助手内部，并层的方向只由三层行数的配比决定。

**叶比意图细一倍多，所以极差更大，也更容易是噪声。** 68 个叶里 43 个的界面差异显著、25 个不显著（interface_bu_leaf.csv: 显著）。首位叶换得比 L1 频繁：2025搜索 / 2026搜索 / 助手头部1k 的第一名都是“股票信息查询”（18.474% / 22.752% / 15.789%），助手随机1k 换成“A股个股推荐与走势预测”28.166%，助手语音1k 换成“汇率换算查询”11.1%（coverage.csv: 首位类目）。有效类目数（= exp(熵)）在这层从 23.81（助手随机1k）到 35.8（助手头部1k）（coverage.csv: 有效类目数）。

**真正稳的叶只有三个。** 全部 10 对两两比较都不显著的叶是：查询A股股票及板块信息（288 行，1.26% / 1.35% / 1.158% / 0.709% / 0.9%，极差 0.641pp）、含龙字股票信息查询（108 行，极差 0.42pp）、钢铁股票查询（74 行，极差 0.405pp）（newcombe_bu_leaf.csv 逐叶统计 + matrix_bu_leaf.csv）。**其中只有第一个是“稳”，后两个是“测不动”**：它们在助手三层的条数分别是 3/1/1 与 1/4/0，区间宽到什么都盖得住。查询A股股票及板块信息 是三个里唯一份额真稳的。**但它的叶内部分布不是“稳”，是“测不出”**：2025搜索 vs 2026搜索 的内层TVD 0.0513 低于同源噪声上界 0.1065，超出噪声=否（leaf_intentmix.csv）；这一格只有 126 / 135 行，本表在这个量级上既证不了内部换了、也证不了没换（两年的主导意图都是 查询金融资产实时行情，78.57% → 80.0%）。它在两年里的头名例子没换，都是「a股」；换掉的是后两条（2025搜索「A股」「宁德时代」→ 2026搜索「科创50」「京东方a」，examples_bu_leaf.csv: 取法=流量最高）。**例子上换掉的是标的**；至于“需求没换”，这份表支持不了，只能说这一格的内层差别没超过同源噪声。

**看起来动了、其实区间重叠的两个叶。** 大盘走势查询 极差 1.063pp（最高 助手头部1k 1.263%、最低 助手语音1k 0.2%），10 对里只有 2 对显著；查询概念板块龙头股 极差 1.019pp，同样只有 2 对显著（newcombe_bu_leaf.csv）。在叶这一层，**1pp 上下的极差基本上读不出东西**——助手快照 n≈1,000，一个 1% 的叶的 Wilson 区间宽度就在 1pp 量级（matrix_bu_leaf.csv: 95CI低%/95CI高%）。

**最大的一条缝常常不在界面之间。** 68 个叶里有 22 个，最高快照与最低快照**同时**落在助手三层（matrix_bu_leaf.csv）。除了汇率换算查询（助手语音1k 11.1% vs 助手随机1k 2.026%，+9.074pp [6.973, 11.289]），还有：指数行情查询（助手头部1k 2.842% vs 助手语音1k 0.6%）、蚂蚁庄园今日答案查询（3.368% vs 0.203%）、查询美股行情（2.0% vs 0.101%）、基金净值查询（助手语音1k 1.3% vs 助手头部1k 0.211%）。**这 22 个叶的并层“界面差异”是三层加权平均出来的，方向由 950 / 987 / 1000 三个 n 的配比决定，不是一个界面属性。**

**一个题材被切成五个叶，五个叶同向。** 黄金在这层是 黄金价格与行情查询（497 行）、今日金价查询（227）、实时国际金价查询（164）、黄金价格及黄金股票行情查询（158）、黄金价格查询（126），五个叶的最高快照都是 助手头部1k（matrix_bu_leaf.csv: 最高快照）。这说明**叶的粒度在这个题材上切得比需求细**：读任何单个黄金叶的占比都会低估这个题材，而五个叶同向本身也提示它们之间的边界不是需求边界。金价随时间变化、快照时间又不同，**这个形状先归给题材与时间，不归给界面**。

**并层最悬殊的叶。** A股个股推荐与走势预测：搜索 0.485% vs 助手 14.062%，+13.577pp [12.362, 14.884]；反方向最悬殊的是 股票信息查询 -12.373pp [-13.471, -11.186] 和 股票股吧查询 -10.186pp [-10.748, -9.549]（interface_bu_leaf.csv）。这三项的区间都很窄，是这层里最有把握的几条。

**L2 子意图补上的那件事：L1 的年度位移集中在一个子意图里。** 行情类 2025搜索 → 2026搜索 是 +10.116pp，但拆到 L2 只有 QUOTE_LOOKUP__2（代表串「上证指数」/「美股」）在动：32.356% → 42.054%，+9.698pp [8.362, 11.028]；QUOTE_LOOKUP__1（代表串「今日金价」）15.563% → 15.532%，差 -0.032pp、区间 [-1.036, 0.973] 含 0；QUOTE_LOOKUP__3（代表串是裸代码，如「600986」）6.321% → 6.771%，区间也含 0（newcombe_td_l2.csv）。三个子意图合起来 3,377 + 7,921 + 1,320 = 12,618 行，正是 L1 行情类的全部（matrix_td_l2.csv / matrix_td_l1.csv: 全语料条数）。**L1 那个 +10pp 不是一个整体现象。**

**L2 也是四个层级里“只在搜索出现”的唯一落点。** 股吧被切成 6 个子意图（STOCK_FORUM_VISIT__1 到 __6，2026搜索 占比 0.55% / 2.83% / 3.39% / 2.30% / 1.86% / 3.20%），其中 __4（389 行）与 __5（297 行）在三个助手快照全是 0 条，助手侧期望条数 57.13 / 43.62、P(0)=0，归属判为“仅搜索·真缺席”（interface_td_l2.csv: 另一边期望条数 / 另一边P(0) / 归属）。其余四个都在助手侧留下了行，__6 在 助手随机1k 与 助手语音1k 各有一点（0.101% / 0.2%）；不过 __2、__3、__6 在单个助手快照上仍各有真缺席记录（absence_td_l2.csv 共 11 条真缺席，只有 __1 不在其中）。**这几个子意图的代表串看不出需求差别，差的只是标的**（表 5.1-0：__4「tcl科技股吧」、__5「阳光电源股吧」、__6「中信建投股吧」）——所以“仅搜索”这两项是几何细分的产物，不是两种不同的需求。

**家族层与叶层几乎是同一个划分。** 55 个家族里有 **49 个只包含 1 个叶**（逐行复算 bu_family_final × bu_leaf 交叉表），只有 6 个家族做了真正的合并。证据也可以直接从表上看：两层的快照两两距离几乎一样（2025搜索 vs 2026搜索：家族 0.1603、叶 0.1689；助手随机1k vs 助手语音1k：家族 0.3024、叶 0.3184，pairwise_tvd.csv——两层之差是 0.0086 与 0.0160，都低于同一行的同源噪声上界 0.0602 / 0.0650 / 0.1744 / 0.1960（pairwise_tvd.csv: 同源噪声上界），所以在这两对快照上家族与叶分不出先后），前若干大类的条数逐个相等（股票信息查询 4,364、股票股吧查询 2,318、汇率换算查询 1,555，matrix_bu_family_final.csv / matrix_bu_leaf.csv）。**所以家族层在本领域几乎不提供叶层以外的信息**，除了那 6 次合并。

**那 6 次合并里有一次值得单独说。** 家族“股票与指数行情查询”（655 行）= 指数行情查询 255 + 查询上证指数行情 110 + 查询美股行情 159 + **港股休市查询 131**。也就是说，自下而上这条路线把“休市日程”并进了“指数行情”。这和自上而下的划分对不上：L1 有一个专门的“查询交易日程与市场状态”（93 行），而叶 港股休市查询 的主导意图是“查询金融资产实时行情”、只占 44.3%（matrix_bu_leaf.csv: 主导意图 / 主导意图占比%）。**自下而上这条路线里没有“日程”这个概念**，它按标的与题材聚，不按“要的是价格还是日期”聚。另一次合并“特定股票查询”（182 行）= 含龙字股票信息查询 108 + 钢铁股票查询 74，也是同一个道理：按字面题材合，不按需求合。

**先说结论：这份表里没有一个类是“只在助手里出现”的。** 四个层级的“仅助手”都是 0，“仅搜索”只有 L2 层的 2 个（表 1-总览）。**但这个结论必须连着两条限制读，否则会被读成“助手没有带来新需求”。**

**限制一：检出力是不对称的，而且差一个数量级。** 搜索侧两个快照合起来 19,997 行，助手三层合起来 2,937 行（interface_td_l1.csv: 搜索n / 助手n）。一个类在 950 行的 助手头部1k 里 0 条，单侧 97.5% 上界仍有 0.388%；在 助手随机1k 是 0.373%，在 助手语音1k 是 0.368%（absence_bu_leaf.csv: 该快照上界%）。同样的 0 条落在 9,998 行的搜索快照里，上界只有约 0.04%。**所以“只出现在搜索里”比“只出现在助手里”容易达成得多**——这不是发现，是 n 的结构。最直接的证据：叶层全部 17 条“某快照 0 条”的记录，**缺席快照一律是三个助手快照，两个搜索快照一个 0 格都没有**（absence_bu_leaf.csv: 缺席快照）。

**限制二：判定分三档，只有“真缺席”能当结论用。** 叶层 17 条里 13 条判为真缺席、4 条判为“偏少但证据弱”（金属行情报价查询 在 助手随机1k 与 助手语音1k、钢铁股票查询 在 助手语音1k、ST股票信息查询 在 助手头部1k，期望条数都在 3.4–3.9 之间、P(0) 在 2% 上下）。L2 层还有一条判为“不可判定（样本量不足）”：CHART_LOOKUP__1 在 助手随机1k，期望条数 2.79、P(0)=0.0613（absence_td_l2.csv）。**这一条不能写成发现。**

**真缺席的那几条长什么样。** 叶层 13 条真缺席里，缺在 助手语音1k 的最多——查询上证指数行情、实时国际金价查询、东方财富官方入口查询、银行客服短号查询、查询个股股票信息#49、数字串含义查询、能源资源类股票查询（absence_bu_leaf.csv）。它们自己的流量最高代表串多是短标的名、站点名或纯号码串（「上证指数」「东方财富网」「95588」「725」，examples_bu_leaf.csv: 取法=流量最高）；**“裸号码串”只说得上 银行客服短号查询 与 数字串含义查询 这两个叶**，其余五个是标的名或站点名。而语音快照是 ASR 文本、无标点、约 40 字截断、抽样方式未知，**这类形态差异要先算在仪器上，不能算成需求差异**。另外 4 条缺在 助手头部1k（银行信用卡客服电话查询、查询金融机构24小时人工客服电话、数字串含义查询、金融代码行情查询）、2 条缺在 助手随机1k（国际原油价格行情查询、金融代码行情查询），这些都是单层缺席，不是“助手侧没有”——银行信用卡客服电话查询 在 助手语音1k 有 1.7%、在 助手随机1k 有 0.912%（matrix_bu_leaf.csv）。

**限制三（最要紧的一条）：这套体系是在一份 87% 是搜索行的语料上拟合出来的。** 18 个 L1 意图与整棵聚类树都由这份合并语料一次跑完，而助手行只占 2,937 / 22,934。所以“没有任何一个类只出现在助手里”是**关于交付分区的陈述，不是关于需求本身的陈述**：助手侧独有的东西如果没能长成一个类，它会落进已有的类里——最可能是残余类，而残余类在 助手随机1k 占 16.819%、在 助手语音1k 占 12.0%，都高于两个搜索快照（8.672% / 6.401%，matrix_td_l1.csv）。**这份表能证明的是“没有一个已定义的类是助手独有的”，不能证明“助手侧没有体系外的需求”。**

意图体系自上而下写出、聚类树自下而上长出，两者独立。所以“同一个意图在不同快照里落到不同的叶”是一次测量。本节挑的都是**份额上测不出差别、内部却换了东西**的那几个——这是这份报告独有的一类发现，前面几张表都看不到。

**（1）查找官方渠道与客服入口：份额几乎一样，主导叶换了。** 2025搜索 8.122% vs 助手语音1k 8.6%，差 +0.478pp [-1.198, 2.448]，区间含 0（newcombe_td_l1.csv）。但意图内部的叶分布 内层TVD 0.5707、同源噪声上界 0.2257（超出噪声=是）：2025搜索 的主导叶是 银行客服电话查询（17.73%，形如「农业银行客服电话」），助手语音1k 的主导叶是 查询银行及业务信息（33.72%，这一格里形如「建设银行宜宾市南溪区的开户行行名行号」「金华中国银行营业厅」）（intent_leafmix.csv；例子取自 examples_td_l1.csv 与 examples_bu_leaf.csv 落在同一格的行）。**同一个“找官方入口”的份额，两边装的是不同的东西。** 这个位移在两个搜索快照上都在：2026搜索 vs 助手语音1k 的内层TVD 0.5715、同源噪声上界 0.2569，同样超出噪声（intent_leafmix.csv）。**但时间这一侧本表答不了**：2025搜索 vs 2026搜索 的内层TVD 0.0928 低于同源噪声上界 0.1246、超出噪声=否，主导叶虽然不变，这一格仍读作测不出差别——**既不能拿它排除时间，也不能说两年之间没动**。

**（2）汇率换算查询：反过来看，同一个叶被判成了不同的意图。** 叶份额并层 6.821% vs 6.503%，差 -0.318pp [-1.227, 0.691] 不显著（interface_bu_leaf.csv）。叶内部的意图分布：2025搜索 60.37% 是“查询金融资产实时行情”、2026搜索 73.17%、助手头部1k 76.67%，而 助手语音1k 有 67.57% 是“计算具体金额或利率”（leaf_intentmix.csv: 助手头部1k vs 助手语音1k 内层TVD 0.5207，同源噪声上界 0.1739、超出噪声=是）。例子上看得出来：「日元对人民币汇率」「汇率换算」对「一亿缅币是多少人民币」。**同一批串、同一个叶，落在两个不同的意图上。**

**（3）残余类：份额测不出差别，内部差一半。** 2025搜索 8.672% vs 助手头部1k 9.474%，差 +0.802pp [-0.993, 2.900] 不显著（newcombe_td_l1.csv）。但内层TVD 0.5129、同源噪声上界 0.3166（超出噪声=是）：2025搜索 的主导叶是 股票代码查询（11.53%），助手头部1k 的是 A股个股推荐与走势预测（7.78%）（intent_leafmix.csv）。**两个快照的残余类是两种不同的残余**——一种是分不了类的代码串，一种是缺上文的续问。

**（4）最稳的那个类，内部也换过。** 查询交易日程与市场状态 的五个占比全不显著，但 2025搜索 vs 2026搜索 的内层TVD 是 0.3408，高于同源噪声上界 0.2595（超出噪声=是）：主导叶都是 港股休市查询，占比从 82.93% 掉到 51.28%（intent_leafmix.csv）。**份额一动不动，里面确实换了。** 不过这一格只有 41 / 39 行、观测值离上界不远，**只能说“换了”，换掉多少这份表定不下来**。 助手三层这个类各只有 4 / 4 / 5 行，低于 30 行的测算门槛，内层分布测不了；表里列出的例子（「什么时候上市」「英伟达业绩公布时间」「美股周六周日也休息吗」）与搜索侧的「港股今日休市吗」形态不同，但**这只是例子，不是分布**。

**（5）原来当反例用的两个类，一个测不出、一个反过来。** 蚂蚁庄园今日答案查询 在 2026搜索 与 助手头部1k 的内层TVD 是 **0.0000**，而同一行的同源噪声上界也是 0.0、超出噪声=否（leaf_intentmix.csv）：两边都 100% 落在“获取每日答题活动答案”，这一格里没有可分辨的余地，**只能读作“本表测不出差别”，不能读作“测到了没换”**。另一个例子方向相反：股票股吧查询 在两年之间的内层TVD 0.0303 高于同源噪声上界 0.0182、超出噪声=是（leaf_intentmix.csv），主导意图占比 97.11% → 94.21%——**它是一次测得到的变化，只是幅度极小**。所以这一节立得住的不是“有的类换、有的类没换”，而是：**超出噪声的格子里，幅度从 0.0303 一直跨到 0.5707**；而表里的低值有一部分并不是“低”，是这一格本来就没有分辨力。

**读法提醒：** 表 7-A / 7-B 只在两端都 ≥30 行时计算，所以行数小的类根本不出现在里面。出现在里面的类，**内层TVD 必须先跟同一行的 `同源噪声上界` 比**（intent_leafmix.csv / leaf_intentmix.csv: 同源噪声上界 / 超出噪声；与 pairwise_tvd.csv 同一口径——把两侧的行合起来、按原来的大小比随机对半切多次，取 TVD 的高分位）。**这是一道单侧筛子，不是一个配区间的检验**：超出噪声=是 只说明这一格的差别大过同源抽样造得出来的幅度；超出噪声=否 则两个方向都读不出——既不能说内部换了，也不能说没换。这不是个别情况：表 7-A 的 78 行里 57 行超出噪声，表 7-B 的 123 行里 51 行超出噪声，**7-B 有一多半的格子读不出**。上面每一条的“份额不显著”都来自 newcombe 表，那一半才是配区间的检验。

**这个领域的这份表，具体不能回答下面这些。**

**一、助手侧很多类的 n 小到只能给方向。** 查询交易日程与市场状态 在助手三层各 4 / 4 / 5 行；比较同类金融产品并择优 在 2026搜索 只有 8 行；寻求应急或无征信门槛借款渠道 全语料 30 行，助手头部1k 与 助手随机1k 各 1 行（matrix_td_l1.csv: 各快照_条数）。后者在 助手头部1k 的 Wilson 区间是 0.10% [0.02–0.59]（matrix_td_l1.csv: 95CI低%/95CI高%）——区间上下端差近 30 倍。**这些类的“最高快照”“极差”列可以照抄，但不能拿来排序。**

**二、有些差异被仪器和时间混在一起，这份表拆不开。** 助手语音1k 是 ASR 文本：无标点、约 40 字截断、抽样方式导出方未说明。叶层 13 条真缺席里有 7 条缺在语音，缺的多是短标的名、站点名与号码串——**这类形态差异要先归仪器**。时间那一侧：两个搜索快照都在 7 月初、助手约 8 月下旬、语音时间未知，所以 获取每日答题活动答案（逐日更新）与五个黄金叶（金价随时间走）的快照间差异**不得归因于界面**。另外，同一个字符串在一次运行里必然拿到同一个标签，**所以年度差异只能来自榜单换血，本方法测不到“同一句话含义变了”**。

**三、有几个类的定义本身就含糊，它们的占比要打折读。** 盲评一致性只有 2/5 的三个叶是：数字串含义查询、借款平台正规性查询、加密货币交易所App官方下载地址查询（matrix_bu_leaf.csv: 盲评一致性）。另有五个叶的主导意图占比不到 40%，说明这个叶横跨多个意图：贷款信息查询与办理 23.0%、查询资金产品安全性及存取借贷规则 26.2%、银行存贷款利率与利息查询 28.6%、查询银行及业务信息 35.4%、银行服务信息查询 36.3%（matrix_bu_leaf.csv: 主导意图占比%）。门槛提到 45% 还会进来五个：查询农业银行及农村金融机构信息 40.5%、个人征信查询与信用报告获取 40.8%、保险信息查询 41.6%、银行卡业务办理与异常处理 42.7%、港股休市查询 44.3%——**这条线画在哪里是人定的，不是一个自然分界**。**这五个叶在助手侧不小，但不是最高的那几个**：按 助手占比% 它们分别排第 4 / 6 / 9 / 10 / 12（4.937% / 3.575% / 2.996% / 2.690% / 2.486%，并列时取靠前名次，interface_bu_leaf.csv），合计 490 行 / 助手 2,937 行 = 16.7%。而助手侧最大的三个叶——A股个股推荐与走势预测 14.062%、股票信息查询 8.240%、汇率换算查询 6.503%——主导意图占比分别是 50.8% / 95.5% / 62.6%，都不在这份含糊清单里。所以要打折的是**助手侧银行与信贷那一块**的细分结论，不是助手侧的全部。

**另一层含糊来自标注置信度本身。** td_confidence<0.5 的行在 助手随机1k 占 34.95%（345 / 987）、助手语音1k 占 27.7%（277 / 1000）、助手头部1k 占 11.47%（109 / 950），而两个搜索快照只有 6.49%（649 / 9998）与 3.53%（353 / 9999）（逐行复算 labels_full.csv 的 td_confidence）。bu_ambiguous 同向：助手随机1k 107 / 987 = 10.8%，2026搜索 702 / 9999 = 7.02%。**本报告里助手侧的每一条细分结论，都建立在置信度更低的那批标注上。** 家族层另有两个家族被审计判为 coherent=否（tree_naming.json: families_final）：板块与基金核心数据查询（家族 1，审计备注说两个叶只能宽泛概括）与 股票与指数行情查询（家族 17，审计备注说 港股休市查询 不属于行情查询）——后者正是 §子层 里单独讲的那次合并。

**四、标注层没有第二意见。** 本次是 `mode=fast`，**单标注员，kappa 不存在、不是 1.0**。这份表里每一个占比、每一个区间都建立在一个没有交叉校验的标注层上；区间量的是抽样误差，**不包含标注误差**。

**五、风险与引用。** 风控图层在全语料只命中 5 行：1 行在 2025搜索 的“核实金融平台真伪与合法性”、3 行在 助手随机1k 的“寻求个股买卖与持有决策建议”、1 行在 助手语音1k 的“解释金融术语与基础规则”（逐行回接 risk_screen.json 的命中索引）。引用护栏三层过后可引 22,784 / 22,934 行（summary.json: quotable_rows / n_rows），合计拦下 150 行——风控图层 5 行（summary.json: risk_flagged_rows）、与领域无关的硬规则 59 行、运行自己点名过的 96 个字符串（summary.json: risk_named_strings）命中 91 行，三层有重叠，并集 150 行；逐快照是 2025搜索 67 / 2026搜索 41 / 助手随机1k 24 / 助手头部1k 9 / 助手语音1k 9（逐行复算 p5_snapshot_classes.py 里 quotable 的定义）。**这 150 行一律只作概括、不引原文**，其中 助手语音1k 的“处置账户异常与非预期扣款”有 1 行。需要注意的是：本体系自己有一个“寻求个股买卖与持有决策建议”类，全语料 648 行、助手侧占 15.424%（interface_td_l1.csv），而风控只命中其中 3 行——**per-1k 的风险密度在本领域是下界，不是估计值。**
