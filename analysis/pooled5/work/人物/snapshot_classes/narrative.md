**先说结论，要按层级分开说。** L1 与家族层没有一个某一侧独有的类站得住：L1 的 19 个类全部记为“两界面都有”，仅搜索 0 个、仅助手 0 个（interface_td_l1.csv: 归属）；叶层与家族层各只有 1 个记为“仅搜索”（`查询习近平总书记个人信息与讲话`，17 行对 0 行），而这一条按可检出性判不成立（见下）。**L2 不一样：3 个类记为“仅搜索”，其中两个在助手侧通过了可检出性。**

**L2 那两个是本领域证据最硬的单侧发现。** `PERSON_ATTRIBUTE_LOOKUP__2` 搜索侧 82 行、0.411%，助手侧 0 行；在合并的助手侧 n=1,839 上期望 7.55 条、P(0)=0.0005，判**真缺席**，差 -0.411pp [-0.509, -0.188]，区间不含 0。`GROUP_ROSTER_ENUMERATION__3` 搜索侧 65 行、0.326%，助手侧 0 行，期望 5.99 条、P(0)=0.0025，同样判真缺席（interface_td_l2.csv: 搜索条数 / 搜索占比% / 另一边期望条数 / 另一边P(0) / 缺席判定 / 显著）。两点限制要跟着写：这是**几何细分的 L2**，它们的 L1 母类在两个界面都有；而且判定成立靠的是把助手两层合成 n=1,839，逐快照看它们都到不了（下文两段分别说明）。

**检出力的不对称是结构性的，必须先看 n。** 一个类在 950 行的助手随机1k 上 0 条，单侧上界仍有 0.388%；在 889 行的助手头部1k 上 0 条，上界 0.414%；同样 0 条落在 9,983 行的 2025搜索 上，上界只有 0.037%（absence_td_l1.csv / absence_bu_leaf.csv: 该快照上界%）。**“只出现在搜索里”比“只出现在助手里”容易达成十倍以上**，所以助手侧的每一个 0 条都要先查判定列。

**快照层面通过可检出性判定的只有三条（L1）。** `艺人平台热度数值查询` 在 2025搜索 0 条：期望 210.28 条、P(0)=0，判真缺席——这是 **L1 层**唯一一条落在万行快照上的真缺席，证据最硬。叶层还有一条同样落在万行快照上：`明星百度影响力查询` 在 2025搜索（该快照 n=9,983）期望 125.83 条、P(0)=0，判真缺席（absence_bu_leaf.csv）。另两条落在助手随机1k：`粉丝打榜投票入口` 期望 6.7 条、P(0)=0.0012，`跳转人物站外主页` 期望 5.51 条、P(0)=0.004（absence_td_l1.csv）。叶层另有四条真缺席落在助手随机1k（`肖战个人资料简介查询`、`鞠婧祎资料与送花影响力查询`、`百度送花明星影响力查询`、`查询人物个人资料简历`），以及 `明星百度影响力查询` 在 2025搜索 与助手头部1k（absence_bu_leaf.csv）。

**三条看起来像发现、其实判不成立的。** ① 叶 `查询习近平总书记个人信息与讲话` 在助手两层都是 0 条，聚合口径写作“仅搜索”，但另一边期望条数只有 1.57、P(0)=0.2088，判定是“不可判定（样本量不足）”（interface_bu_leaf.csv / absence_bu_leaf.csv）。② 叶 `查询鹿晗关晓彤近况与感情动态` 在助手随机1k 0 条，期望 2.87、P(0)=0.0565，同样不可判定。③ L2 的 `RELATIONSHIP_AND_FAMILY_STATUS__1`（代表串是某位公众人物的子女一类的亲属追问，命中引用护栏，不引原文）33 行全在搜索侧、助手 0 行，聚合口径记作“仅搜索”，但在合并的助手侧 n=1,839 上期望 3.04 条、P(0)=0.0477，只到“偏少但证据弱”（interface_td_l2.csv: 另一边期望条数 / 另一边P(0) / 缺席判定）。逐快照看更弱：absence_td_l2.csv 给它两行——助手头部1k 期望 1.4 条、P(0)=0.2457，助手随机1k 期望 1.5 条、P(0)=0.2221，两行都是“不可判定（样本量不足）”。同一批 0 条，两个口径判定不同，差别全在 n。**这三条都不能写成“助手上没有这种需求”。**

**合并助手两层会把判定改写，那是检出力，不是新证据。** L2 的 `GROUP_ROSTER_ENUMERATION__3`（代表串「七一勋章获得者名单」）在助手头部1k 与助手随机1k 上各自都只到“不可判定”（P(0)=0.0628 与 0.0515，absence_td_l2.csv）；把两层合成 n=1,839 的助手侧以后，期望 5.99 条、P(0)=0.0025，判真缺席。同一批 0 条，判定不同，差别全在 n。

**最后一条限制，必须写明。** 这套体系是在一份搜索行占 91.6% 的语料上拟合出来的（19,965 / 21,804，interface_td_l1.csv: 搜索n / 助手n）。所以“没有任何一个类只出现在助手里”是关于**交付分区**的陈述，不是关于需求本身的陈述——助手上独有的表达如果没有对应类目，会被并进已有的类。这件事在表里留下了痕迹：残余类 `垂类外非人物查询` 在助手随机1k 是第一大类，18.947%（matrix_td_l1.csv）。

意图体系自上而下写出、聚类树自下而上长出，两者独立。所以“同一个意图在不同快照里落到不同的叶”是一个测量。49 对可算的比较里，**有 28 对的主导叶换了**（intent_leafmix.csv: 主导是否相同）。

**份额测不出差别、内部却换了主导叶——这是本报告独有的一类发现。**

① `人物近期事件状态查询` 在助手两层的份额是 8.886% 对 8.947%，差 0.061pp、区间 [-2.574, 2.673] 含 0（newcombe_td_l1.csv）。但它内部的叶分布 TVD 有 0.5062、同源噪声上界 0.2401，判超出噪声，主导叶从 `查询明星娱乐八卦动态` 49.37% 换成 `查询人物背景与个人生活` 45.88%（intent_leafmix.csv: 内层TVD / 同源噪声上界 / 超出噪声）。两侧各 79 行与 85 行，刚过 30 行门槛，**只能说主导叶换了，不能给份额区间**。

② `公共职务现任者查询` 的搜索/助手聚合差 0.022pp、区间含 0（interface_td_l1.csv），而 2025搜索 对助手随机1k 的内层 TVD 有 0.7253、同源噪声上界 0.2939，判超出噪声，主导叶从 `党委书记及常委任职查询` 40.98% 换成 `查询对象身份` 26.47%（intent_leafmix.csv: 内层TVD / 同源噪声上界 / 超出噪声，两侧 305 行与 34 行）。助手那一侧只有 34 行，这条只作方向性描述。

**反过来的一类同样值得看：份额搬了近 20pp，内部动得小得多。** `裸名人物身份识别` 一年掉了 -19.638pp、`人物档案调阅` 涨了 19.085pp（newcombe_td_l1.csv），而两者的内层叶分布 TVD 是 0.0294 与 0.1015，两条都超出各自的同源噪声上界（0.0254 与 0.0405），主导叶两年都是 `人物资料查询`（分别 69.65%→71.08% 与 77.23%→81.28%，intent_leafmix.csv: 内层TVD / 同源噪声上界 / 超出噪声）。这两个类在 intent_leafmix.csv 的全部 6 对比较里，主导叶**一次都没换过**。

**这两条也不能写成“没动”——内层 TVD 必须跟同一行的同源噪声上界比。** 上界与 `pairwise_tvd.csv` 同一口径：把两侧的行合起来、按原来的 n_a / n_b 比例随机对半切，取 TVD 的 95 分位；观测值不超过它，这一格就读作“测不出差别”。`intent_leafmix.csv` 与 `leaf_intentmix.csv` 现在都带 `同源噪声上界` 与 `超出噪声` 两列，直接读表即可。按这两列：`裸名人物身份识别` 的 0.0294 对上界 0.0254、`人物档案调阅` 的 0.1015 对上界 0.0405，**两格都判超出噪声**，年度的内部移动都是可测的——后者主导叶没换，但 `人物资料查询` 在它里面从 77.23% 移到 81.28%。上界随 n 走：这两格两侧分别有 6913 / 4952 行与 1076 / 2981 行，上界因此只有 0.0254 与 0.0405，很小的 TVD 也能判出来。本节依赖的其余几条离上界更远：0.5062 对 0.2401、0.7253 对 0.2939、0.2783 对 0.0216（intent_leafmix.csv / leaf_intentmix.csv: 内层TVD / 同源噪声上界 / 超出噪声）。反面的样子在同一张表里就有：49 行里 3 行判 `超出噪声=否`——`性化类目浏览或非具体人物浏览` 的 0.0701 对上界 0.1929、`垂类外非人物查询` 的 0.1279 对 0.1371、`作品角色反查人物` 的 0.2028 对 0.3034（都是 2025搜索 对 2026搜索）。**这三格既不能读成“内部换了”，也不能读成“内部没换”，只能读成本表测不出。**

**叶那一侧给出镜像的一条。** `人物资料查询` 这个叶的份额从 58.449% 升到 63.504%（+5.055pp [3.702, 6.405]，显著），而它内部的意图构成从 `裸名人物身份识别` 82.52% 变成 55.53%，内层 TVD 0.2783、同源噪声上界 0.0216，判超出噪声（leaf_intentmix.csv: 内层TVD / 同源噪声上界 / 超出噪声）。**同一个叶、同一个名字，两年里装的意图换了一大块。** 把它当成一个稳定的需求桶去做同比，会直接读错。

**哪些意图的落点最不稳定。** 主导叶每一对都换的是 `私人家世与感情关系查询`（6/6）、`人事任免事件查询`（3/3）、`人物单项属性查询`（3/3）、`人物相关说法核实`（1/1）、`人物肖像图片获取`（1/1）；`人物近期事件状态查询` 5/6、`垂类外非人物查询` 5/6。**除 `人物肖像图片获取` 外，其余四个都是助手侧份额明显更高的类**——它们在搜索侧的条数小，聚类给它们的落点本来就不稳。`人物肖像图片获取` 要摘出去单列：它搜索侧 1.463%、助手侧 1.251%，助手反而更低（interface_td_l1.csv: 搜索占比% / 助手占比%），而它在 intent_leafmix.csv 里唯一的一对是 2025搜索×2026搜索（两侧 77 行与 215 行），换的是年份，不是界面。反面是 `裸名人物身份识别`、`人物档案调阅`、`作品角色反查人物`、`跳转人物站外主页`、`性化类目浏览或非具体人物浏览`，主导叶一次都没换。

**这份表不能回答的，具体到本领域。**

**① 小格子。** `黑料绯闻炒作查询` 全语料只有 28 行（2026搜索 2 行、助手头部1k 11 行），`作品本体获取` 42 行，`人物相关梗与说法解释` 48 行，叶 `查询习近平总书记个人信息与讲话` 17 行（matrix_td_l1.csv / matrix_bu_leaf.csv: 全语料条数）。这些类的任何单快照占比都不要当水位读，也不要跨快照做倍数。

**② 助手侧的分辨率下限。** 助手两层分别只有 889 行与 950 行，一个类在那里 0 条时上界仍有 0.414% 与 0.388%。**任何真实占比低于约 0.4% 的类，在助手侧“没有”和“有但很少”分不开**，独有性一节里三条“不可判定”正是这个原因。

**③ 被时间与仪器混淆的差。** 两个搜索快照都在 7 月初、助手约在 8 月下旬，所以随时间走的题材（人事任免、当期舆情）在界面轴上的差不能归因于界面。`粉丝打榜投票入口` 与 `艺人平台热度数值查询` 量的是一个搜索站内的功能位——前者在助手随机1k 判真缺席、后者在 2025搜索 判真缺席（absence_td_l1.csv）——这两条读成“入口在不在”，不是“需求有没有”。本领域只有四个快照，**输入方式那条对比线整条缺席**，不要读成“测了，没有差别”。

**④ 标注层没有第二意见。** 本次是 `mode=fast`：单标注员，**kappa 不存在，不是 1.0**。上面每一个占比都建立在一个未经第二意见校验的标注层上。

**⑤ 定义本身含糊的类。** 5 个叶的主导意图占比不到 35%：`查询人物背景与个人生活` 17.4%、`查询明星娱乐八卦动态` 27.1%、`人物及机构基本信息查询` 28.1%、`查询对象身份` 31.9%、`列举特定对象的重要成果与相关条目` 34.6%（matrix_bu_leaf.csv: 主导意图占比%）。盲评一致性方面，`人物年龄及属性查询` 只有 2.0，另有 6 个叶是 3.0（matrix_bu_leaf.csv: 盲评一致性）。这些叶的跨快照差异要连着它们自身的边界质量一起读。家族层则不承载分组：35 个家族里只有 1 个含两个叶，按家族做的任何分组分析在本领域等于按叶做。L2 子意图没有名字，只能按 `L1编码__序号` 引用，代表串仅供辨识、不是定义。

**⑥ 结构上测不到的。** 同一个字符串在一次运行里必然同标签，所以年度差异只可能来自哪些串进出了前一万，“同一句话的含义变了”本方法看不见。助手两层与搜索两层是四份导出文件，它们之间的分布差是文件的差，不是同一批人在不同界面上的行为差。

**⑦ 引用护栏。** 本领域几乎每一行都指向真实的人，长尾里有大量普通个人。涉及私人个体的个人信息、成人内容、未成年人相关内容一律不引原文，只给条数与来源分布。可引比例本身就能看出压力：`群体名单枚举` 在 2025搜索 的 209 行里只有 126 行可引，在助手随机1k 的 107 行里只有 82 行可引；`人物相关说法核实` 在 2025搜索 的 35 行里只有 24 行可引（examples_td_l1.csv: 该类该快照条数 / 可引条数）。本叙述引用的例子全部取自公众人物、历史人物或虚构角色的公开检索式，例如「肖战百度送花入口」「七一勋章获得者名单」「香港四大才子」「卧龙凤雏」。
