# 医疗8 引文隐私筛查标准（所有筛查员共用）

逐条读每一个查询串，判断**把它当作报告里的「真实例子」原文印出来**是否违反下列任一条。只看串本身，不猜来源。
正当的就医、症状、用药、性健康与生殖健康问题**本身不算**违规；违规看的是写法与对象。拿不准时：前 3 类与第 5、6 类宁可标（置信度写「中」），第 4 类按下面的说明。

| 码 | 什么时候标 |
|---|---|
| MINOR_SEX | 未成年人线索（明确年龄不满 18、「十几岁」「未满十八」、初中 / 小学 / 高中 / 中学生、女孩 / 男孩 / 女生 / 小孩 / 宝宝 / 儿童等）与性、性器官、性行为、怀孕、取精、恋物或任何性化描述同时出现。 |
| EXPLICIT_SEX | 露骨的性行为或性器官描写；色情片或成人站标题式写法（职业角色 + 性、按摩 + 私处、多人、偷拍、暴露、异物进入私处等）；成人站引流词或俗称；恋物与性化猎奇（包括以女孩 / 女生为对象的挠痒、脚心、捆绑类题材）。普通的性健康问题（如「早泄怎么治疗」「同房后出血是什么原因」）不标，除非写法露骨、猎奇或像标题党。 |
| NAMED_PERSON | 能识别到具体个人：医生、专家、院长、主任、教授的全名，或姓 + 头衔（「王院长」）；私人全名；带人名的坐诊或出诊信息。泛称（「皮肤科医生」「老中医」）不标。 |
| NAMED_PRIVATE_FACILITY | 点名一家具体的私立 / 民营医院、诊所、门诊部、医美、整形、体检、中医馆等机构。**拿不准是否公立时也标**（置信度「中」）。公认的公立医院（「北京协和医院」「华西医院」「XX市第一人民医院」「XX大学附属XX医院」「XX市中医院」）不标；只有地名 + 泛称（「上海的三甲医院」）不标。 |
| SELF_HARM_CRISIS | 自杀、自伤意图或方法；主动求致病、致伤的方法；以伤害为目的的过量服药；误食、误吞、过量后的求救。 |
| ILLEGAL_REPRO | 非医学需要的胎儿性别鉴定或选择（含试管 / 三代选男孩女孩）、代孕、买卖精子或卵子。 |
| PII | 电话号码、身份证号、住址、病历号、微信号等可识别个人的信息。 |

输出只列**要标的串**：sid、码、置信度（高 / 中）、一句理由（理由里**不要抄录原文**，用「年龄线索 + 取精」这种概括）。
