# 健康管家「产品层 vs 用户内容」盲标码本（医疗3，2026-09-17）

这份码本**重建**自 health-pool3 的盲标：当时它写在工作流提示里，没有落盘。码、兜底规则与三个视角
都按当时的产物复原（`AUDIT_TIER`、`ai_audit_labels.csv` 的票型、`medrand_audit_aggregate.py` 的
`LENS_ORDER`）。**因为是重建，必须先证明它复刻了原来的仪器**——所以这一轮除了新串，还重标了
原来 1,192 串里的一个随机样本，与当时存下来的票逐条比对，结果写在报告里。

## 判什么

健康管家的导出里混着两种东西：**用户自己键入的内容**，和**产品自己吐出来的字**（作答选项、功能按钮、
推送问题、医生卡、空回应）。只有前者是"查询"。这一层判的就是：**这一串是人打的，还是产品印的？**

## 码

| 码 | 含义 | 典型形态 |
|---|---|---|
| `A` | 作答选项 | **从清单里选出来的，不是打出来的。** 判别痕迹见下面「A 的识别 signature」 |
| `F` | 功能或卡片按钮 | 产品的功能入口或卡片分面，如「找医生」「report 解读」这类固定标签 |
| `P` | 推送问题 | 助手主动推的问题卡，句式完整但语气是产品在问用户 |
| `D` | 医生卡 | 医生 / 机构卡片带出的串（姓名 + 科室 + 职称这类组合） |
| `C` | 无内容 | 空回应、纯标点、致谢、"好的""嗯"这类不含诉求的串 |
| `U` | 用户键入 | 上面都不是——这是人自己打进去的内容 |

### A 的识别 signature（最容易判错的一个码）

**「描述自己的症状」不等于「用户键入」**——分诊表单的选项本来就是在描述症状。这是重建第一版最大的错误：
实测它比原仪器少删 21.3 个百分点，而且偏差**完全集中在 A 这一个码上**（原仪器判 A 的 84 串，第一版只认 13 串）。

一串是选项而不是键入，看的是它**有没有被人组织成一句话**：

- (a) **选项兜底词**：出现「都没有」「都不是」「不清楚」「没有」，尤其在末尾或与其它短语并列——
  这就是多选表单里「以上都没有 / 不确定」那一格；
- (b) **平列的症状或属性**，用逗号或斜杠隔开，彼此之间没有连接词、没有主语、也没有问句
  （「白带量多，发黄/灰白，有腥臭味」「活动时疼,腰臀僵硬」）；
- (c) **纯检查数值罗列**（「低密度脂蛋白1.7总胆固醇4.4血糖5.7」）；
- (d) 内容是自己的情况，但语法上不是一句话，而是若干个被勾选的条目。

反过来：带主语、带诉求、带疑问、或句法完整的，哪怕很短，也是 `U`。

## 兜底规则（不可协商）

**拿不准是产品层还是用户内容时，一律判 `U`。** 这条规则的方向是故意的：多留一条用户内容只是让
语料多一点噪声，错删一条用户内容则是把真实需求从分析里抹掉，而且抹掉之后没人看得见。

## 三个视角

每个视角**独立看同一批串**，互相不知道对方的判断，也不知道规则词表命中了什么。

- **origin（来源视角）**：先不看这串长什么样，只问「这句话最可能是谁打出来的」。
  一个正在用健康助手的人，会在输入框里打出这一串吗？还是这更像界面上被点了一下的东西？
- **standalone（独立性视角）**：把这串单独拿出来，它还成立吗？
  用户键入的内容通常自带诉求，脱离上下文也读得懂；作答选项和分面按钮往往必须挂在上一个问题下才有意义。
- **form（形态视角）**：只看表面形态——长度、是否完整句、有无人称、有无问句标记、是否平行短语、
  是否像一个标签而不是一句话。不揣测意图，只描述这串写成了什么样子。

三个视角各出一个码；聚合时取多数（≥2 票），三票各异记 `NOMAJ`。

## 这一层怎么用（与 health-pool3 一致）

- **三票一致且一致判为非用户内容，才删。**
- 分票（包括 `NOMAJ`）一律保留为用户内容。
- 盲标判 `U` 的行，即使规则词表命中也保留。
- 没被盲标覆盖的行，只有三个窄规则（功能/卡片位、医生卡、无内容）可以删。

## 修订记录

**2026-09-17，第 1 次修订：收紧 `A` 的定义。** 第一版在 300 串校准样本上与原仪器的删/留结论只一致 78.7%，
偏差且是**单向**的——重建版从不多删（多删 0 串），但少删 64 串，其中 71 串原仪器判 A、重建版判 U。
读过那批分歧串后定位到原因并补上了「A 的识别 signature」。修订的是**定义**，不是逐串改判；
改完在同一批 300 串上重测，结果写在报告里。必须修的理由：这一层要与另外两个快照对比，
仪器比它们宽松就会把仪器差异算到快照头上。第一版的全部产物留在 `audit_v1/` 与 `audit_labels_v1.csv`。
